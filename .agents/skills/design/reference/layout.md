# レイアウト

一覧と詳細を扱う画面の標準構成を定義する。すべての製品にこの画面構成を追加するのではなく、必要なパターンだけ採用する。
文字・色・形は [基礎仕様](foundations.md)、部品の内部寸法は [コンポーネント](components.md) を参照する。

## 幅による構成

| 項目               | 狭い画面：900px 未満             | 広い画面：900px 以上                       |
| ------------------ | -------------------------------- | ------------------------------------------ |
| 基本構成           | 一画面に一覧または詳細のどちらか | 左に一覧、右に詳細                         |
| 一覧の幅           | 利用可能な幅すべて               | 352px。縮ませない                          |
| 一覧と詳細の境界   | 画面遷移で分ける                 | 1px の区切り線                             |
| 一覧のグループ     | `surface` の面でまとめる         | 基本は透明。行の選択だけ面を付ける         |
| 一覧の左右余白     | 16px                             | 12px                                       |
| グループ間         | 16px                             | 8px                                        |
| 詳細の主コンテンツ | 全幅で連続して読める面           | 外側に 24px の余白を取り、パネルとして置く |

```text
狭い画面                         広い画面
┌───────────────────┐           ┌─────────────┬─────────────────────┐
│識別情報    補助操作│           │識別情報     │詳細の見出し         │
│ページ見出し       │           │ページ見出し ├─────────────────────┤
├───────────────────┤           │             │                     │
│グループ           │  選択 →   │一覧         │詳細・本文           │
│  名前      状態  ›│           │  選択中     │                     │
│  名前      状態  ›│           │             ├─────────────────────┤
│別のグループ       │           │補助ナビ     │入力・主操作         │
└───────────────────┘           └─────────────┴─────────────────────┘

選択後は詳細を全幅表示。
戻る操作で一覧に戻る。
```

幅が変わっても機能や選択対象は変えない。一覧を隠す場合は戻る経路を残し、一覧へ戻ったときに文脈を失わせない。
ブレークポイントを変更する場合は、端末名ではなく一覧と本文が読める幅から判断する。

## 高さとスクロール

- アプリ型の画面では外枠を `100dvh` に合わせる。対応環境のフォールバックとして `100%` を先に指定できる。
- 上部の識別・見出し、本文のスクロール領域、下部の入力・操作領域を分ける。スクロールを重ねず、一覧と詳細それぞれに一つの主スクロール領域を置く。
- 残りの領域を伸縮させる要素には `flex: 1`、`min-width: 0`、`min-height: 0` を設定する。本文が親の幅や高さを押し広げないようにする。
- 長い一覧では上部と補助ナビを残し、項目の部分をスクロールさせる。短い一覧を無理に画面下まで引き伸ばさない。
- 入力欄がある場合は本文をスクロールさせ、入力と送信を画面下部に残す。画面が低くなっても操作を本文の外へ追い出さない。
- 読み物やログインなど、内容が画面より長くなるパターンには `min-height` を使い、ページ全体をスクロールできるようにする。

## 上部とページ見出し

| 領域                       | 狭い画面                            | 広い画面                          |
| -------------------------- | ----------------------------------- | --------------------------------- |
| 上部の識別情報と補助操作   | 上 16px、左右 20px、下 8px          | 最小高 76px、上下 16px、左右 24px |
| ページ見出しの外側         | 上 16px、左右 24px、下 24px         | 上 24px、左右 24px、下 24px       |
| ページ見出しと補助情報の間 | 8px                                 | 8px                               |
| 詳細の上部バー             | 最小高 56px、内側 16px、要素間 12px | 左右の内側だけ 32px に広げる      |

詳細の上部は「戻る」「名前と補助情報」「状態」の順に置く。狭い画面で幅が足りなければ状態を次の行へ送り、名前を潰さない。
広い画面で一覧が常時見える場合、一覧へ戻るだけの重複したボタンは省ける。

## 詳細の分割

広い画面では、同じタブのペインを最大 4 枚まで並べて見られる。上部バーの右端で 1 枚表示と切り替える。

| 枚数 | 並べ方                     |
| ---- | -------------------------- |
| 2    | 左右                       |
| 3    | 左に 1 枚、右に 2 枚を上下 |
| 4    | 2x2                        |

区切りは 1px の `line` で、セルの隙間から見せる。狭い画面では分割せず、ペインを切り替えて 1 枚ずつ見る。

ペインの ID とコピーはヘッダー行（上部バー）に置かず、ペインの上端右に出す。分割したときも各セルが自分の ID を持つ。

## 補助ナビゲーション

設定が必要な製品では、狭い画面は一覧の右上のアイコンボタン、広い画面はサイドバー下部の文字付き行を標準の入口にする。
この下部領域は低頻度の操作用とし、重要な状態や主操作を置かない。
広い画面の下部領域は上 12px・左右 16px・下 16px の余白を取り、上辺を `line` の 1px 線で区切る。下の余白は safe area より小さくしない。

ログアウトがある場合は設定内にまとめ、一覧の下部や主操作の隣に常設しない。
設定やアカウント自体が不要な製品には、この入口や画面を作らない。既存のナビゲーションがある製品へ別の入口を重ねない。

## 設定・短いフォーム

- 内容の最大幅は 560px。広い領域では中央に置き、横に引き伸ばさない。
- 狭い画面の外側余白は上 32px・左右 20px、広い画面は上 48px・左右 40px。
- 見出しの補助説明は 8px 下、セクションの開始は 32px 下に置く。
- 値が長い場合はラベルと値を別行にし、値を縮小して横一行に収めない。

## safe area と仮想キーボード

- 全面表示が必要な場合だけ `viewport-fit=cover` を指定し、`env(safe-area-inset-*)` を外枠と下部操作の余白に反映する。
- 下部の内側余白は通常の余白と safe area の大きい方を採る。ホームインジケーターに操作を重ねない。
- `dvh` だけで仮想キーボードに対応できると決めつけない。必要な環境では `visualViewport` の変化を外部入力として扱い、見える高さに合わせる。
- 画面幅だけでなく、横向きやキーボード表示時の低い画面でも本文を縮めて操作を残す。
