# 基礎仕様

このファイルは色・文字・余白・形・アイコンの標準値を定義する。寸法の `px` は CSS px を表す。
既存のデザインシステムへ適用する場合は役割で対応付け、同じ意味のトークンを増やさない。

## 色

ニュートラルな背景を重ね、内容と操作を引き立てる。色名は見た目ではなく役割で定義する。

| CSS トークン           | 役割                                     | ライト    | ダーク    |
| ---------------------- | ---------------------------------------- | --------- | --------- |
| `--color-bg`           | 画面全体の背景                           | `#f4f5f7` | `#101215` |
| `--color-surface`      | グループ・設定行・入力領域の外側         | `#ffffff` | `#1b1e23` |
| `--color-raised`       | 控えめなボタン面・ホバー・無効時の面     | `#eef0f3` | `#262a31` |
| `--color-content`      | 連続して読む詳細・コード・入力欄の内側   | `#ffffff` | `#131619` |
| `--color-text`         | 主情報                                   | `#18212f` | `#f2f4f7` |
| `--color-secondary`    | 補助情報・プレースホルダー・補助アイコン | `#5d6878` | `#a3aab5` |
| `--color-accent`       | 主操作・リンク・選択の強調・フォーカス   | `#255cd6` | `#94baff` |
| `--color-on-accent`    | アクセント面の上の文字・アイコン         | `#ffffff` | `#101215` |
| `--color-selected`     | 選択された行の面                         | `#e9f0ff` | `#23334e` |
| `--color-line`         | グループ内の区切り・装飾的な輪郭         | `#dce0e7` | `#32373f` |
| `--color-control-line` | 入力欄など識別が必要な輪郭               | `#8490a1` | `#606976` |
| `--color-active`       | 進行中の状態文字                         | `#4f5f73` | `#c9d1dd` |
| `--color-active-bg`    | 進行中の状態ラベル面                     | `#eef1f5` | `#2b3038` |
| `--color-attention`    | 確認・対応が必要な状態文字               | `#a34c0a` | `#f6c57f` |
| `--color-attention-bg` | 確認・対応の状態ラベル面                 | `#fff0da` | `#352b1e` |
| `--color-success`      | 完了・正常の状態文字                     | `#216549` | `#8fdbb1` |
| `--color-success-bg`   | 完了・正常の状態ラベル面                 | `#e6f3ed` | `#20392e` |
| `--color-neutral`      | 待機など中立の状態文字                   | `#5d6878` | `#b6becb` |
| `--color-neutral-bg`   | 中立の状態ラベル面                       | `#eef0f3` | `#2b2f36` |
| `--color-danger`       | 破壊的操作・アカウントから離れる操作     | `#b3333c` | `#ff9ca4` |

- アクセントは操作と選択に使う。状態の区別には状態トークンを使い、すべての状態をアクセント色にしない。
- 状態ラベルの文言は対象の意味に合わせる。トークン名を業務の状態名や API の値として流用しない。
- 端末設定への追従は `prefers-color-scheme` と `color-scheme` で実現する。指定がなければ独自の外観切替を増やさない。
- 透過を前提にせず、不透明な面で階層を作る。背景画像や blur に可読性を依存させない。

### コントラスト

通常の文字は 4.5:1 以上、大きな文字は 3:1 以上を確保する。大きな文字は通常ウェイトで 24px 以上、太字で約 18.7px 以上が目安。
識別が必要なアイコンや入力欄の輪郭は、隣接する背景と 3:1 以上を目安にする。装飾的な区切り線を文字や操作アイコンに転用しない。

標準トークンの組み合わせは次のとおり。色を変更したら実際の組み合わせで再計算する。

| 前景 / 背景                | ライト  | ダーク  |
| -------------------------- | ------- | ------- |
| `text` / `surface`         | 16.19:1 | 15.17:1 |
| `secondary` / `surface`    | 5.65:1  | 7.14:1  |
| `secondary` / `bg`         | 5.18:1  | 8.02:1  |
| `accent` / `surface`       | 5.87:1  | 8.54:1  |
| `on-accent` / `accent`     | 5.87:1  | 9.58:1  |
| `control-line` / `content` | 3.24:1  | 3.27:1  |

コントラストを増やす設定では、補助文字をライトで `#303b4b`、ダークで `#e1e5eb`、区切り線をライトで `#8490a1`、ダークで `#8792a1` にする。色以外の状態表現も残す。

## 文字

UI はシステムのサンセリフ体を使う。識別子・コード・整形済みの出力だけ等幅にし、長い説明文まで等幅にしない。

```css
:root {
  --font-ui: -apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans", sans-serif;
  --font-mono: ui-monospace, "SFMono-Regular", Consolas, monospace;
}
```

| スタイル                   | 狭い画面  | 広い画面  | ウェイト | 行高                    |
| -------------------------- | --------- | --------- | -------- | ----------------------- |
| ページ見出し               | 1.75rem   | 1.5rem    | 600      | 1.2                     |
| 本文・行の名前・操作ラベル | 1.0625rem | 0.9375rem | 400      | 1.5                     |
| 補助情報・状態ラベル       | 0.8125rem | 0.8125rem | 400      | 1.5。状態ラベル内は 1.4 |
| コード・整形済みの出力     | 0.9375rem | 0.9375rem | 400      | 1.85                    |

`rem` はブラウザ既定の文字サイズを基準にし、ルートの文字サイズを固定しない。既定が 16px なら、狭い画面の本文は 17px になる。
グループ名と選択された行の名前は本文サイズのまま 600 にする。使うウェイトは 400 と 600 に絞る。
ページ見出しだけ字間を `-0.035em` にし、本文や識別子は通常の字間にする。

長い名前では先に行高を伸ばす。名前・補助情報・状態を必要に応じて折り返し、文字サイズを下げて収めない。
入力欄は `max(16px, 本文サイズ)` とし、フォーカス時の意図しない拡大を避ける。

## 余白と形

- 余白は 4px を最小単位にし、主に 8px のリズムで組む。使う値は 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48px を基本とする。
- 関係が近い情報には小さい余白を、異なるグループには大きい余白を使う。同じ種類の要素で余白をそろえる。
- 枠線は原則 1px。輪郭が必要な操作と、区切りだけの線を色の役割で分ける。
- 原則として影を付けない。面の明度差、余白、細い区切りで層を作る。

| 角丸の役割                       | 値   |
| -------------------------------- | ---- |
| 小さいラベル・リンク             | 8px  |
| 小さいアイコン枠                 | 10px |
| 操作ボタン・選択行               | 12px |
| グループ・入力枠・一般的なパネル | 16px |
| 空状態の大きいマーク             | 24px |

## アイコン

- SVG を使う。基準キャンバスは 24 × 24、線幅 1.7、`fill: none`、線端と接合部は丸。
- 通常は 20 × 20px、disclosure と小さいアイコン枠の中は 16 × 16px、空状態のマークは 32 × 32px。
- 色は `currentColor` で文字と合わせる。同じ UI の中で別の線幅や絵文字を混ぜない。
- アイコンの見た目の寸法と、クリック・タップできる領域の寸法を区別する。操作領域はコンポーネント仕様に従う。
