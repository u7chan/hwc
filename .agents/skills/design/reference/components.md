# コンポーネント

部品は [基礎仕様](foundations.md) の色・文字・角丸を組み合わせる。以下の色名は `--color-` を省略して表記する。
画面外側の寸法は [レイアウト](layout.md)、操作・状態の振る舞いは [操作と検証](interaction.md) を正とする。

## 1. 上部の識別情報と補助操作

構成は「任意のマーク → 画面または製品の名前」と「補助情報 → アイコンボタン」の二つのまとまり。
左右に分け、両端に配置する。画面が狭い場合は折り返しを許す。

- マークは 32 × 32px、角丸は小さいアイコン枠、輪郭は `control-line`、面は `surface`。
- マークと名前の間は 8px。名前は本文サイズ・600。
- 補助操作のまとまりは要素間 12px。左右のまとまりの間は 16px、折り返した行の間は 8px。
- 補助情報は補助文字。小さい状態点を使う場合は 6 × 6px とし、8px 離して文言を添える。
- 名前やマークがリンクなら、見た目の高さとは別に 44px 以上の操作領域を確保する。

## 2. グループ化された一覧

### 構成

```text
グループの面
├─ 開閉ボタン
│  ├─ グループのアイコン
│  ├─ 主情報
│  │  ├─ 名前
│  │  └─ 件数などの補助情報
│  └─ disclosure
└─ 子の一覧
   ├─ 項目へのリンク
   └─ 項目へのリンク、または必要な下位グループ
```

### 寸法

| 部分                   | 狭い画面                  | 広い画面               |
| ---------------------- | ------------------------- | ---------------------- |
| 外側の面               | `surface`、グループの角丸 | 透明、操作ボタンの角丸 |
| グループの開閉ボタン   | 最小高 76px、内側 16px    | 最小高 64px、内側 12px |
| 開閉ボタンの要素間     | 12px                      | 12px                   |
| グループのアイコン領域 | 32 × 32px                 | 同左                   |
| 子の一覧の内側余白     | 上 0、左右 8px、下 8px    | 上 0、左右 4px、下 8px |

グループ名は本文サイズ・600、補助情報は 4px 下に置く。主情報を伸縮させ、disclosure は右端に残す。
開閉ボタンは行全体を操作領域とし、名前だけをクリック可能にしない。

### 階層が必要な場合

- 下位グループは上 4px・左 16px 離し、左側に `line` の 1px 線を置き、線から中身まで 8px 取る。
- 下位グループの開閉行は最小高 60px、上下 12px・左右 8px。名前は本文・400 に戻し、親との差をつける。
- さらに小さい見出し行が必要なら、最小高 44px、内側 8px、要素間 8px、補助文字を使う。子の左余白は 16px。
- 名前が長い場合も disclosure の領域を残す。階層の深さを文字サイズの縮小で表現しない。
- 中間の見出しを省くかどうかは、対象の情報構造から判断する。サンプルの件数や特定の階層構造を製品の仕様にしない。

## 3. 項目の行と選択状態

構成は「任意のアイコン枠 → 名前と補助情報 → 任意の状態ラベル」。行全体を遷移リンクにする。

- 最小高は狭い画面で 64px、広い画面で 60px。内側は上下 12px・左右 8px、要素間は 12px、行間は 4px。
- アイコン枠は 32 × 32px、`line` の 1px 輪郭、小さいアイコン枠の角丸。中のアイコンは小サイズ。
- 名前は本文サイズ。補助情報は 4px 下に置く。主情報を伸縮させ、名前と補助情報は折り返せるようにする。
- 状態ラベルとの間は 8px。幅が足りなければ状態ラベルを次の行へ送る。
- 通常の面は透明、ホバーは `raised`。選択された行は `selected` の面、名前は `accent`・600、アイコン枠の線とアイコンは `accent`。
- 選択中は `aria-current` など意味を持つ属性でも表す。ホバーしても選択の面を失わせない。

## 4. 状態ラベル

構成は「状態を表す記号 → 文言」。色と記号と文言を組み合わせる。

- 補助文字、行高 1.4、内側は上下 4px・左右 8px、要素間 4px、小さいラベルの角丸。
- 記号の領域は幅 12px。進行・対応待ち・完了・中立で識別できる形にする。
- 状態の文字色と同じ役割の `*-bg` を組み合わせる。記号の違いを色だけに置き換えない。
- ラベル内は折り返さず、ラベル自体を次の行へ移動できるようにする。文言が長い場合は意味を失わない短い表示名を検討する。
- 状態を示すだけのラベルをボタンのように見せない。操作できる場合は別途、操作であることを示す。

## 5. ボタンとリンク

| 部品                 | 構成と寸法                                                                                      | 面と文字                                           |
| -------------------- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| アイコンボタン       | 44 × 44px の正方形、中央に通常サイズのアイコン、操作ボタンの角丸                                | `raised` / `text`                                  |
| 入力に添える主操作   | 狭い画面は 44 × 44px、広い画面は最小高 44px・左右 16px。広い画面だけ 8px 離して文言を添えてよい | `accent` / `on-accent`、600                        |
| 全幅の主操作         | 最小高 56px、内側 16px、アイコンと文字の間 8px、グループの角丸                                  | `accent` / `on-accent`、600                        |
| 全幅の注意を伴う操作 | 主操作と同じ寸法                                                                                | `surface` / `danger`                               |
| 文字リンク           | 最小高 44px、内側 8px、アイコンとの間 8px、小さいリンクの角丸                                   | 透明 / `accent`                                    |
| サイドバー下部の行   | 最小高 44px、内側 12px、要素間 12px、操作ボタンの角丸                                           | 透明 / `secondary`。選択時は `selected` / `accent` |

リンクは遷移、ボタンは実行・開閉に使う。アイコンだけのボタンには、動作が分かるアクセシブルな名前を付ける。
主操作の無効時は `raised` / `secondary` とし、実行を抑止する。クリックできる見た目のまま説明なく無反応にしない。
画面内で強い塗りの主操作を競合させない。

## 6. 詳細・整形済みの出力

- 主コンテンツの面は `content`。広い画面では上辺と左右に `line` の 1px 枠、上側に一般的なパネルの角丸を付ける。
- 内部の補助見出しは上 16px・左右 20px・下 8px。広い画面では左右だけ 24px にする。複数の補助情報は 8px 離して折り返す。
- 本文領域の内側は上 16px・左右 20px・下 24px。広い画面では左右 24px。
- 普通の本文には本文スタイルを使う。コードや整形済みの出力だけコードスタイルを使い、空白を保ちつつ長い行を折り返す。タブ幅は 2。
- 文字を選択・コピーできるようにする。長い内容はこの領域をスクロールさせる。
- 表やコードなど横方向の意味を保つ必要がある場合だけ、対象領域の横スクロールを許す。ページ全体を横にはみ出させない。

## 7. 入力と送信

```text
入力の目的・対象が分かるラベル
┌───────────────────────────┐
│入力欄                 送信│
└───────────────────────────┘
フィードバック      操作ヒント
```

- 外側は狭い画面で内側 16px、上辺に `line` の 1px 線、面は `surface`。下部は safe area を考慮する。
- 広い画面では上 20px・左右 24px・下 24px にし、外側の上辺線と面をなくして本文とつなぐ。
- ラベルは補助文字で、入力枠まで 8px 空ける。
- 入力枠は内側 8px、要素間 8px、`control-line` の 1px 枠、面は `content`、一般的なパネルの角丸。送信は右下にそろえる。
- 複数行入力は最小高 64px、最大高 `30dvh`、内側は上下 4px・左右 8px。文字は基礎仕様の入力サイズ・行高 1.5。ユーザーによる縦方向のサイズ変更を妨げない。
- 枠の下は 8px 空け、補助文字でフィードバックと操作ヒントを置く。狭い画面では折り返し、キーボードショートカットの説明は必要に応じて省く。
- この部品は入力が必要な画面にだけ置く。詳細ページだからという理由で常に送信欄を追加しない。

## 8. 設定などのラベルと値

- セクション名は補助文字・400。グループの左端にそろえ、グループまで下 12px。
- グループは `surface` とグループの角丸。行は最小高 64px、左右はグループ端から 16px、上下は 16px。
- ラベルと値を両端へ配置し、値は補助文字。横の間隔は 16px、折り返した行の間は 8px。
- 隣接する行だけ `line` の 1px 線で区切る。線は行の左右端にそろえ、グループの外側まで延ばさない。
- 補足説明はグループから下 12px で、グループの左右端にそろえる。注意を伴う全幅操作が必要な場合は 32px 離す。
- 読み取り専用の値には遷移用の矢印を付けない。操作できる行は行全体を操作領域にする。

## 9. 空状態と単一目的の開始画面

### 空状態

中央に「任意のマーク → 見出し → 理由や次の操作 → 必要ならリンク」を縦に置く。
外側は 32px、マークは 80 × 80px・空状態の角丸・`surface` と `line`、中のアイコンは大サイズ。マークの下は 24px。
見出しはページ見出し。説明は最大幅 28rem、上 12px・下 16px、色は `secondary`。
何も選ばれていない状態、データがない状態、取得できない状態を同じ文言にしない。

### 単一目的の開始画面

内容は最大幅 360px。通常は上下中央、画面が低ければ全体をスクロールできる構成にする。
外側は上下 32px・左右 24px を下限に safe area を考慮する。
識別情報が必要なら見出しの 48px 上、見出しから説明まで 16px、説明から全幅の主操作まで 32px、主操作の補足は 16px 下に置く。
見出しはページ見出しのサイズ・600、行高だけ 1.4 とする。
ログインや初期設定に使えるが、認証方法やフォーム項目は対象の要件で決める。
