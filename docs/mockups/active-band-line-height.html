アクティブ帯の行間と見切れ

帯の見出し・リポジトリ名・ブランチは 1 行省略のため overflow: hidden を持ちます。行間が 1.2 だと Noto Sans JP の文字面が行ボックスに収まらず、英字の降下部分（g / p / y / j の下）が切れます。下の 3 案は、切る位置と帯の高さのどちらを取るかの違いです。

現状

line-height 1.2

破線（見出しの行ボックスの下端）が g の降下部分にかかり、下端が平らになる。帯の高さは今のまま。

破線は見出しの行ボックスの下端（ここで切り取られる）。4 倍で表示。

案 1

line-height 1.5

破線が文字の下へ抜け、切れない。余白はそのままなので、帯は行間の増えたぶんだけ高くなる（PR の無い帯で 1px 程度、PR チップのある帯は数 px）。

破線は見出しの行ボックスの下端（ここで切り取られる）。4 倍で表示。

案 2

line-height 1.5 + 余白 4px

切れない。上下の余白を 8px から 4px に詰めるので、帯は今より PR の無い帯で約 4px、PR チップのある帯でも約 4px 低くなる。

破線は見出しの行ボックスの下端（ここで切り取られる）。4 倍で表示。
