ファイルツリーのアイコン — デザインモック

ツリーの行の左に SVG のアイコンを付け、設定で見た目を選べるようにする案です。既定は今の見た目（アイコンなし）で、切り替えない限り何も変わりません。

モック 実装ではありません。アイコンの形・割り当て・色は暫定です。本番のトークンと寸法（行の高さ 44px、字下げ 12px、記号の欄 16px、線 1.7）に合わせ、色はテーマごとに調整済みの ANSI 色を借りています。採用したのは「矢印なし＋色分け」で、ほかの案は比べるために残しています。
アイコン（設定に入れる項目）

1. 2 つの段階 — 同じツリーで比べる

「なし」が既定で今の見た目です。「色分け」は種類ごとに色を変えます。形はどちらも同じで、印を出すかどうかだけが違います。

2. 置き方 — 矢印なしに決定

シェブロンの位置にフォルダを置く「矢印なし」を採りました。幅も名前の位置も今のままで、開閉はフォルダの形で分かります。「フォルダも」は記号の欄が 1 つ増えて名前が 24px 右へ寄り、「ファイルだけ」はフォルダの形が出ません。

3. 設定 › 表示（スマホ幅）

「ファイルツリーの幅」の下に 1 つ足します。段階は 2 つで、既定は「なし」です。サンプルは選ぶとその場で変わります。

テーマの選択（変更なし）

ファイルツリーのアイコン

ファイルとフォルダの行の左に印を付けます。フォルダは開くと形が変わります。既定の「なし」は今の見た目です。

サンプル

サンプルは幅 260px・文字 17px です。

実装するときの置き場所

値は端末ごとの見え方なので、文字の大きさ・幅と同じく localStorage に置きます（hwc-file-tree-icons）。BFF には送りません。

種類は、行が持つ名前の拡張子から決めます。開けない行（open === null）は今までどおり淡色で、記号も地の色のままです。

ファイルの種類は、src/client/icons.tsx に足します。file / folder / image は既存のものをそのまま使え、code は木の中で少し大きくします。フォルダは開閉の 2 形を用意し、行の aria-expanded で入れ替えます。開いた形は面も塗ります（今のシェブロンの回転のような動きは付けません）。

4. アイコンと拡張子

8 種類だけに絞ります。細かく分けるほど 16px では見分けられず、拡張子が増えるたびに手入れも要るためです。当てはまらないものは書類 1 枚にします。

5. 決めたこと

  1. 置き方は「矢印なし」。シェブロンの位置にフォルダを置くので、名前の幅は今のままで、開閉もフォルダの形で分かります。「押すと開く」の合図はフォルダの形だけになりますが、行そのものがボタンなので、当たり判定は変わりません。
  2. 色分けは独自の色を足さず、ANSI 色を借ります。ANSI 色は明暗 2 通りに調整済みで、20 テーマすべてに付いて回ります。アイコン専用の色を 20 テーマぶん足すのは手入れが重すぎます。その代わり、端末の文字用の値なので画面では少しすくんで見えます。ロックだけは黄がデータと重なるので色を付けません。
  3. 「文字（バッジ）」案は作りませんでした。16px の枠に 2〜3 文字を収めると 7px 前後になり、スマホでは読めません。読ませるなら枠を広げる必要があり、名前の幅を削ります。
  4. 拡張子の割り当ては 4 節の表のとおり。テスト（*.test.ts）はコードと同じ扱い、Markdown は書類に寄せます。
  5. 設定の段階は「なし / 色分け」の 2 つ。「単色」は落としました。テーマ 20 種すべてで地の文字色に寄り、種類を見分ける役に立たないためです。
