ファイルツリーの表示設定 — デザインモック

設定の「表示」に、ファイルツリーの文字の大きさと幅を足す案です。段階を選ぶと、サンプルとセル幅ごとの並べ方がその場で変わります。

モック 実装ではありません。段階の値は暫定で、保存もしません。本番のトークンと寸法（行の高さ 44px、字下げ 12px、アイコン 16px）に合わせています。

設定 › 表示（スマホ幅）

既存の「位置」の下に 2 つ足し、最後にサンプルを置きます。

テーマの選択（変更なし）

システムは端末の外観設定に合わせます。

ファイルツリーの位置

広いセルでツリーを会話の左右どちらに並べるかです。狭いセルでは会話の上に重ねます。

ファイルツリーの文字の大きさ

行の高さは変わりません。大きくすると、1 行に入る文字が減ります。

ファイルツリーの幅

広いセルでツリーを並べるときの幅です。広くするほど、並べるのに必要なセルの幅も増えます。狭いセルでは会話の上に重ねるので、幅は変わりません。

効き方 — セル幅ごとの並べ方

並べるのは、セルの幅が「ツリーの幅 + 本文 420px」以上のときだけです。幅を広げると、並べられるセルが減ります。位置の左右も、ここに反映されます。

確認したい点

  1. 段階の値（文字 14 / 17 / 20px、幅 220 / 260 / 340px）。標準は現状のままです。
  2. 並べる条件を「ツリーの幅 + 420px」に変える点。幅「広」では 760px 未満のセルで重ね表示になります。
  3. サンプルは付けるか。付けないなら、設定の画面は Segmented 2 つと注記だけで済みます。
