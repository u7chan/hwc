A: Git アイコン＝スペースメニュー

推奨

先頭の Git アイコンを押すとスペースメニューが開きます。↑↓ は右端のラベルにし、0 でないときだけ出します。 右端の「…」はペインメニューのままなので、Git 関連はそちらに出しません。 worktree でも Git アイコンは常にあるため、upstream が無くてもメニューからリポジトリへ行けます。 GitHub リモートが無い場合や GitHub 以外のリモートの場合は、リポジトリ名は文字だけにし、メニューの項目も出しません。

B: Git アイコン＋↑↓を左にまとめる

比較

A の変形で、↑↓ を Git アイコンのすぐ右に置きます。Git 関連の情報と入口が 1 か所にまとまりますが、 名前の開始位置が右へずれ、狭い画面では名前が削られやすくなります。

↑1↓2
↑↓ を左に寄せた場合。名前の幅がその分だけ狭くなる。

C: 「…」ボタンを常設する

比較

束ね見出しのバリエーション

確認点

同じリポジトリの worktree が複数あるときの束ね見出しです。本体（host）があるときは host のメニューを開き、 本体が無いときは束ね見出しにメニューを持たせず、各 worktree 見出しの Git アイコンから開く案です。

A: 本体あり。束ね見出しの Git アイコンは host のスペースメニューを開く。
↑1↓2
B: 本体なし。束ね見出しは静的で、各 worktree 見出しの Git アイコンから開く。
