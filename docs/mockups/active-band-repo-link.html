アクティブ帯のリポジトリ名をリンクにする

帯の2段目、GitHub 記号とリポジトリ名をまとめて repoUrl へのリンクにします。 PR チップと同じく1タップで GitHub を開けます。リンクになるのは GitHub のリモートがあるときだけで、 帯の高さは今のまま（56px／PR チップがあるときは約64px）です。

案: GitHub 記号＋リポジトリ名を1つのリンクにする

推奨

記号だけをリンクにすると、押せる範囲が 13px の絵になり、名前を押しても反応しません。 記号と名前を1つのリンクにまとめ、押下・ホバー・フォーカスでは PR チップと同じ背景を出します。 アクセント色は帯に3つ目の青が増えるため、常時は付けません。

タップ領域: 32px と 44px

判断点

帯は 56px（PR チップがあると約64px）。2段目は約16pxしかないため、44px の操作領域は帯の中に収まらず、 タイトル行と下のペイン行にはみ出します。破線はリンクの操作領域です。

判断メモ

  • 1 記号と名前を1つのリンクにする。記号だけをリンクにすると 13px の絵が的になり、名前を押しても反応しない。リンクの読み上げは「acme-dashboard を GitHub で開く」にし、記号は aria-hidden にする。
  • 2 帯の高さは変えない。2段目に 32px の箱を置くと、帯は 56→68px（PR ありは 64→80px）に伸びる。sticky の帯が太ると一覧が狭くなる。見た目は行のまま、::after で 32px の的だけを取る。
  • 3 44px は採らない。帯の内側に収まらず、タイトル行と最初のペイン行に重なる。タイトルは読むだけの面なので、押したときに GitHub が開くのは驚きになる。32px は PR チップと同じ扱いで、下のペイン行には出ない。
  • 4 アクセント色は常時付けない。帯に3つ目の青が増え、タイトルと PR チップが弱くなる。押下・ホバー・フォーカスでは背景を変え、押せたことを返す。
  • 5 リンクは repoUrl があるときだけ。ローカルのみ・GitHub 以外のリモート・git 管理外は今までどおり文字だけ。リンク先はリポジトリのトップ（ブランチページは未 push で 404 になる）。
  • 6 ADR 0083 の改訂が必要。「記号は読む面であって入口ではない」を撤回し、ADR 0017 の帯の記述も合わせる。E2E は架空 git の repoUrl で、リンク先・新しいタブ・リモートなしの帯を確認する。
