# ADR 0032: Codex のフォルダ信頼確認はチャットを確認ビューへ切り替えて回答する

- Status: Accepted
- Date: 2026-11-06

## Context

Codex CLI 0.166.0 は未登録のフォルダを開くと `Folder access` の確認で止まる。この間の通常のメッセージ入力は役に立たず、文字や停止キーを送ると別の操作として解釈され得る。確認は、フォルダ内の設定や hooks による自動実行を許可する判断でもある。

端末操作の全再現は目指さない。今回必要なのは、この既知の確認に明示的に回答することと、GUI では回答せず Herdr 本体へ操作を引き継ぐことである。

## Decision

- 今回の対象は Codex の `Folder access` の信頼確認だけとする。通常のチャットを、信頼対象のパス・注意事項・「信頼して続行」「ターミナルで操作」のビューへ切り替え、入力欄と停止操作は出さない。下書き・添付・引用は捨てない
- 判定と回答の正は BFF とする。表示中の Codex ペインは、会話を読める間も端末出力の既存ポーリングを続ける。判定は `pane.read` の `detection` を使い、過去の出力や端末のスクロール位置から承認しない
- 既知の注意文・選択肢・フッターが揃い、「Trust and continue」が選択中で、信頼対象の完全なパスを読める場合だけ回答可能にする。リポジトリルートへの適用を示す注記があれば、そのルートを信頼対象として表示する。省略・折り返しでパスが特定できない場合や、確認に見えるが形式が一致しない場合は閲覧専用の端末表示にする
- BFF は観測した確認へ識別子を発行する。回答 API は識別子だけを受け取り、最新のエージェント状態と確認画面を照合してから、Herdr の `pane.send_keys` へ Enter だけを 1 回送る。任意のキーやパスは受け取らない。通常入力と停止 API から既知の確認へ回答・キャンセルさせない
- 同じペインの判定・回答を直列化し、回答を始めた確認は送信結果が不明でも再送しない。応答が返っても確認の解除までは入力欄を戻さず、端末出力と Herdr の状態を正として復帰する。再描画や一時的な読み取り不全で送信済みの記録を消さない
- 空・空白だけの detection は解除の証拠にせず、閲覧専用の端末表示にする。確認識別子と送信済み記録を保持し、同じ確認が戻っても再発行・再送しない
- 「ターミナルで操作」はキーを一切送らず、確認を保留して閲覧専用の端末表示へ切り替える。拒否・キャンセルとは呼ばない。操作は Herdr 本体で行う。同じ確認の識別子はブラウザ内でペインを切り替えても自動再表示しない。ページ再読み込みを越える永続化は持たない
- サーバー状態はスナップショットで置き換え、クライアントには保留した確認の識別子と送信リクエストの状態だけを持たせる。会話履歴へ確認や回答を追記しない
- クライアントの試行状態は識別子ごとに App が持つ。ペイン切替で詳細や確認ビューを外しても、送信中・解除待ち・結果不明の記録を失わない。HTTP 要求も確認ビューの破棄だけでは中断せず、既存の期限内で結果を受け取る
- ADR 0016 の汎用キー操作を持たない方針に対する、この確認への回答だけの例外とする。Claude や他の確認、汎用キー操作、自動承認は対象外とする

## Consequences

- 端末の文言・選択記号に依存する。CLI の表示変更や小さすぎる端末では、推測で承認せず端末表示に戻る
- Herdr の読み取りとキー送信は原子的な操作ではない。直前の再照合と二重送信の抑止を行っても、その間の Herdr 本体での同時操作との競合は残る
- 回答送信が失敗または不明になった場合は、再送ボタンではなく端末での確認を案内する。BFF の再起動を越える回答済み記録は持たない
- 確認の表示はメッセージと選択肢の部品に分けるが、未実装の CLI 向けの判定器・設定・拡張機構は追加しない

## Verification

- unit で画面の識別、信頼対象、選択変更、古い識別子、同時回答、送信結果不明時の無再送、通常入力・停止からの無送信を確認する。結果不明の回答後に空出力を挟み、同じ確認が戻っても識別子と送信済み記録を保持する経路も含める
- 架空 Herdr の E2E で、会話のない起動時と保存済み会話のあるペインの表示切り替え、保留、確認解除後の復帰、下書き保持を確認する。回答の送信中・結果不明時に別ペインへ移動して戻っても、同じ識別子へ HTTP を再送しないことを確認する。実 Herdr や実 Codex の信頼設定は変更しない
