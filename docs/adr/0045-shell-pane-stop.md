# ADR 0045: シェルペインは前景プロセスを C-c で止め、動いている間だけタブ名をコマンドにする

- Status: Accepted
- Date: 2026-11-08

## Context

[ADR 0025](0025-stop-working-agent.md) の停止ボタンは、既知のエージェントに Esc を送るだけだった。シェルは対象外で、`bun run dev` のようなサーバーを hwc から止める手段が無い。スマホには Ctrl+C が無く、入力欄に文字を送っても実行中のコマンドの標準入力に届くだけで、止まらない。

Herdr は `pane.send_keys` で `C-c` を受け付ける。実機では `sleep 100` を `C-c` で止めてプロンプトに戻ることを確認した。`pane.process_info` は `shell_pid`、`foreground_process_group_id`、前景プロセス群の `cmdline` を返すので、何か動いているかと何が動いているかは分かる。

ただし前景プロセスの変化はイベントで降ってこない。`pane.updated` はプロセスの開始・終了では流れず、スナップショットにも載らない。表示するには誰かが定期的に読む必要がある。

## Decision

- BFF に `GET /api/panes/:id/process` を足し、`pane.process_info` を `{ running, command }` に畳んで返す。`running` は前景プロセスグループがシェルと別かどうか、`command` は前景プロセス群の最も深い（最後の）`cmdline` とする
- クライアントは、開いているタブのシェルペインだけを 3 秒間隔で読む。`document.visibilityState` が `hidden` の間は読まず、可視に戻った時点で 1 回読む
- 停止はペインの種類で分ける。シェルは前景プロセスが動いているときだけ `C-c` を送る。プロンプトへの `C-c` は入力中の行を消すだけなので送らず、成功として返す。エージェントは ADR 0025 の Esc のまま
- 入力欄のボタンは、入力が空で前景プロセスが動いているときに停止にする。文字・添付・引用・チップがあれば送信のまま（REPL への入力や、実行中への追加指示を残す）
- タブの見出しは、シェルでコマンドが動いている間だけコマンドのプログラム名（`cmdline` の先頭トークンの basename）にする。止まれば元のペイン名に戻す。コマンド行全体は `title` と `aria-label` に置く
- Herdr のタブラベルとペインラベルは書き換えない。名前の正は Herdr のままとし、hwc は表示だけを差し替える

## Consequences

- 開いているタブのシェルペイン数だけ、3 秒ごとにソケットを 1 往復する。タブは最大 4 ペインなので、可視中は最大 4 リクエスト / 3 秒
- 「サーバー」と「その他のコマンド」は区別しない。`vim` や `sleep` でもタブ名は変わり、停止ボタンも出る。コマンド名の判定に開発サーバー固有の知識を持ち込まないため
- 一覧の行はポーリングしないので、ペイン名のままになる。コマンド名が出るのは詳細のタブだけ
- Herdr TUI のタブ名は変わらない。TUI でも同じ名前にしたいときは、コマンド側が `herdr tab rename "$HERDR_TAB_ID" ...` を呼ぶ
- 前景プロセスの判定は Herdr の `process_info` に依存する。`foreground_processes` が空でも前景グループがシェルと違えば「動いている」とし、`command` は null にして名前は変えない
- 停止は `C-c` を 1 回送るだけで、実際に止まったかは保証しない。状態は 3 秒後の読み直しで反映される
- エージェントのペインは対象外。`pane.agent` を持つペインは ADR 0025 の経路だけを使う

## Verification

- unit で、`process_info` の畳み込み（アイドル、深いコマンド、コマンド行なし、別ペイン、壊れた応答、長い行の切り詰め）、シェル停止の `C-c` とアイドル時の無送信、`canStop` の分岐、タブ名の決定を確認する
- 架空 Herdr の E2E で、シェルペインのタブ名がコマンドになり、停止ボタンが出ること、押すと `^C` が出力されてタブ名と送信ボタンが戻ること、入力中は送信ボタンのままであることを確認する。実 Herdr のプロセスは止めない

## Alternatives

- **Herdr のタブラベルを hwc が書き換える**: 手で付けた名前を上書きし、元の名前を hwc 側に持つ必要がある。TUI と Web で名前の所有者が二重になる
- **コマンド側が `pane.report_metadata` で名乗る**: サーバーごとに実装が要り、hwc から起動したコマンド以外では動かない
- **`cmdline` のパターンや listen ポートでサーバーを判定する**: ツールごとの知識が BFF に溜まり、判定を外したときに静かに壊れる
