# ADR 0010: 認証を置かず LAN に公開する

- Status: Accepted
- Date: 2026-10-20

## Context

主な利用端末はスマホ（iOS Chrome）で、同じ LAN 内のブラウザから操作する。WSL2 は NAT モードのため、WSL 内で `0.0.0.0` にバインドするだけでは LAN から届かず、ホスト側のポート転送が到達性を作る。認証の仕組みは未実装。

## Decision

`0.0.0.0:30000` で待ち受け、認証を置かない。到達範囲はホストのファイアウォール規則で LAN に限定する。ポートは `PORT` で上書きできる。

## Consequences

- LAN 内の誰でも Herdr のペインを操作できる
- ファイアウォール規則が任意の送信元を許可している間は、信頼できないネットワークからも到達し得る
- loopback に戻すとスマホから接続できなくなる
- LAN の外からアクセスする場合は、必ず VPN を経由する
- 認証は次のフェーズで追加する（QR コードの読み取りでトークンを発行する想定）

## Revisit

認証を導入したとき、またはホストのファイアウォール規則を LAN 限定に変更したとき。
