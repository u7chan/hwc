# ADR 0010: 認証を置かず LAN に公開する

- Status: Accepted
- Date: 2026-10-20

## Context

主な利用端末はスマホ（iOS Chrome）で、同じ LAN 内のブラウザから操作する。旧クライアントが使っていたポート 30000 はファイアウォールで許可済み。認証の仕組みは未実装。

## Decision

`0.0.0.0:30000` で待ち受け、認証を置かない。LAN 内は信頼できる前提で、スマホからの接続を優先する。ポートは `PORT` で上書きできる。

## Consequences

- LAN 内の誰でも Herdr のペインを操作できる
- loopback に戻すとスマホから接続できなくなる
- 公開範囲を LAN の外へ広げる場合は、認証の追加が前提になる
- iOS の Chrome は WebKit なので、ブラウザ検証は iOS 上の単一エンジンで足りる
