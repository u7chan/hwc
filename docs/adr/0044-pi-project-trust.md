# ADR 0044: Pi のプロジェクト信頼確認も確認ビューで回答する

- Status: Accepted
- Date: 2026-11-08

## Context

Pi は、信頼対象のリソース（`.pi` の設定・MCP・拡張・スキル・プロンプト・テーマ・システムプロンプト、プロジェクトの `.agents/skills`）を持つフォルダを開くと `Trust project folder?` の選択で止まる。既定の選択は `Trust` で、Enter だけで確定する。選択肢は 5 つあり、親フォルダの信頼、セッション限りの信頼、拒否も選べる。Herdr が返す `detection` の画面には、シェルが pi を起動したコマンドの行がタイトルの上に残る。タイトルが画面の先頭に来ることはない。

[ADR 0032](0032-codex-folder-trust.md) は Codex の `Folder access` だけを対象にした。Pi の確認も同じく起動を止め、選ぶまで会話が始まらない。しかも Herdr 0.9.5 の pi 検出マニフェストはこの画面を `blocked` としないため、hwc は通常の入力欄を出したままにしていた。その入力欄の Enter は信頼の回答として Pi に届く。フォルダを信頼するかどうかは、フォルダ内の拡張を無言で実行してよいかの判断でもある。

## Decision

- Pi の `Trust project folder?` を、ADR 0032 と同じ確認ビューで回答する。回答できるのは既定の `Trust` だけとする。親フォルダの信頼、セッション限り、拒否は答えない。それらは端末で行う
- 判定と回答の正は BFF のまま（ADR 0032）。判定は `pane.read` の `detection` を使い、画面から確認を読む。`blocked` を待たない
- 回答可能なのは、タイトル・信頼対象の完全なパス・注意文・5 択・フッターが揃い、`→ Trust` が選択中のときだけ。注意文と選択肢は端末幅で折り返されるため、行数ではなく空白を畳んだ 1 行で照合する。パスが省略・折り返しで特定できないときは回答しない。信頼確認は起動直後の画面の末尾に描かれるので、最後に現れたタイトルから下だけを読み、フッターより下に出力が続く画面は回答しない。タイトルより上は、シェルが打った起動コマンドの行などを含み得るので照合しない。確認に見えるが形式が一致しない画面は閲覧専用にする
- 閲覧専用にする手掛かりは、信頼確認に固有の文言（タイトルと選択肢の同時出現）を基本とする。汎用のフッター（`↑↓ navigate`）は Pi の選択ダイアログ全般に付くため、セッションが始まる前のペインに限って使う。信頼確認はセッション開始前にだけ出るので、会話を持つペインでは出力に同じ文字列が出ていても通常の入力欄を保つ
- BFF が発行する確認の識別子は、ペイン・エージェント・信頼対象の組に対して発行する。ペインが別のエージェントや別のフォルダの確認に変わったら、古い識別子では Enter を送らない
- 確認中の通常入力と停止は、Codex と同じく `confirmation_pending` で拒否する。停止は `working` のときしかキーを送らないので、`idle` で出る Pi の確認画面には送られない
- 確認ビューの注意文はエージェントごとに変える。Pi には Pi の説明（`.pi` の設定・スキル・拡張の読み込み、不足パッケージの導入、拡張の実行）を出し、Codex の権限説明を使い回さない
- 起動時に `--approve` は渡さない。無言で信頼することになり、利用者の判断が GUI に残らない。Pi の保存済み判断（`~/.pi/agent/trust.json`）にも残らない
- pi 拡張の `project_trust` イベントから BFF へ問い合わせる案は採らない。拡張の注入と起動時の待ち合わせが要り、既知の 1 画面には過剰
- ADR 0032 の機構（送るのは Enter だけ、直列化、送信結果が不明なら再送しない、識別子の保持、「ターミナルで操作」で保留）はそのまま使い、対象の記述だけをこの ADR に合わせる

## Consequences

- Pi の画面の文言・選択記号・フッターに依存する。Pi の表示や既定の選択順が変われば、推測で承認せず端末表示に戻る
- 信頼した判断は Pi が `~/.pi/agent/trust.json` に保存する。同じフォルダの次のペインでは確認が出ない
- Herdr が Pi の確認を `blocked` としないため、一覧の行は `idle` のままになる。確認が必要なことは、開いているペインの確認ビューだけが知らせる
- 親フォルダの信頼、セッション限りの信頼、拒否は GUI から選べない。端末で行う
- 幅の狭いペインで注意文や選択肢が崩れた場合、回答できないことがある。そのときは端末表示になる

## Verification

- unit で、Pi の完全な画面、起動コマンドの行が上に残った画面、折り返された注意文と選択肢、選択違い、フッターより下に出力が続く画面、エージェントの取り違え、識別子の再発行、Enter 1 回、空画面と送信結果不明時の無再送を確認する
- 架空 Herdr の E2E で、会話のない Pi ペインが確認ビューに切り替わること、回答後に端末表示へ戻ること、「ターミナルで操作」でキーを送らないことを確認する。実 Herdr や実 Pi の信頼設定は変更しない
