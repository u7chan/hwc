# ADR 0082: コンテキスト使用量の注記は情報アイコンで開く

- Status: Accepted
- Date: 2026-11-14
- Revises: [ADR 0036](0036-input-hint-panel.md) の「コンテキスト使用量の読み上げ専用パネル（`role="tooltip"`）」

## Context

入力欄のコンテキスト使用量のパネルは、末尾に「設定枠はモデル仕様上の最大値とは限りません。自動圧縮は枠に達する前に行われることがあります。」を常時出していた。幅 240px で 3 行になり、パネルの高さ 258px のうち 63px を数値でない説明が占める。スマホでは入力欄の上に開くため、パネルが高いほど上端が詰まる。

注記は、割合を「まだ余裕がある」と読ませないための補足で、毎回読む値ではない。数値の行と同じ面に常時置く必要はない。一方で、消すと設定枠の意味を読む手段が無くなる。

パネルはボタンを含むため、ADR 0036 の規則では `role="group"` とする。標準の `title` はタッチとキーボードで読めないため、注記の入口には使えない。

## Decision

- タイトル行の右端に情報アイコンのボタンを置き、注記は既定で隠す。押すと同じパネル内のタイトル直下で開閉し、下の行は押し下がる
- 注記はタイトル直下に置く。パネルは下端を札に合わせて上へ伸び、入る高さが足りないときはパネル内をスクロールする。末尾に置くと、開いた注記がスクロールの外へ隠れる
- 記号は 16px に保ち、触れる範囲は `::after` で 44px に広げる。モデル名のコピーボタンと同じ `.hwc-hint-icon-button` を使う
- パネルは `role="group"` と `aria-label="コンテキスト使用量"` に変える。ボタンを含むパネルを `role="group"` とする ADR 0036 の規則に合わせる。札の `aria-describedby` と `aria-expanded` はそのまま
- ボタンは `aria-expanded` と `aria-controls` を持ち、開いている間は背景を `raised` にする
- 開いた状態はパネルを閉じても保つ。ペインを切り替えると既定へ戻る

## Consequences

- 390px 幅の 6 行の例で、パネルの既定の高さは 258px から 195px になる。注記を開くと 258px に戻る
- タイトル行の右端に 44px の触れる範囲が増える。上端はパネルの内側 2px まで、下端は 1 行目の右端に 10px 掛かる。値は操作できないため、押しても起きるのは注記の開閉だけ
- 注記は開いた状態でパネルを閉じても残る。同じペインで開き直すと、前回の状態のまま出る
- `role="tooltip"` ではなくなったため、読み上げではパネルが「コンテキスト使用量」のグループとして扱われる

## Alternatives

- **注記からさらに吹き出しを開く**: `.hwc-hint-panel` は `overflow-y: auto` なので、中の絶対配置はパネルのスクロール箱で切られる。`position: fixed` も、開閉のアニメーションに残る `transform` が containing block を作るためパネル基準になり、同じく切られる。回避はポータルかパネル外の兄弟要素で、[ADR 0036](0036-input-hint-panel.md) が 1 か所に集めている配置計算を分けることになる。閉じる条件（外側の pointerdown・`Escape`・focusout・pinned）も層ごとに分ける必要がある。注記は 2 文で、層を増やすコストに見合わない
- **常時表示のまま 1 行に縮める**: モデル仕様の上限との違いと、自動圧縮が枠の手前で起きることを 1 行で伝えられない
- **注記を消す**: 設定枠がモデル仕様の最大値とは限らないことを読む手段が無くなる
- **閉じるたびに既定へ戻す**: パネルの開閉を監視する effect が要り、閉じるアニメーションの途中でパネルの高さが変わる
- **行のラベルを `自動圧縮の枠` に変える**: 自動圧縮が枠の手前で起きることは伝わるが、設定枠がモデル仕様の上限と違うことは伝わらない
