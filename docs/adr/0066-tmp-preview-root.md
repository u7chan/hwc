# ADR 0066: `/tmp` を既定のプレビュー根にする

- Status: Accepted
- Date: 2026-11-11
- Revises: [ADR 0051](0051-agent-html-preview.md) の「追加の根は既定で空」
- Revises: [ADR 0041](0041-agent-message-images.md) の「`/tmp` の画像は既定では出ない」
- Revises: [ADR 0065](0065-outside-preview-root.md) の「移動を依頼」と、`/tmp` を根にしない判断

## Context

[ADR 0051](0051-agent-html-preview.md) は、チェックアウトの外へ書いた HTML を `HWC_PREVIEW_ROOTS` に足したときだけ配信すると決めた。[ADR 0065](0065-outside-preview-root.md) は、根の外のファイルを黙って落とす代わりに、1 行の案内と `移動を依頼` のボタンを出した。

実際のエージェントは、使い捨てのモックやスクリーンショットを `/tmp` に書く。`/tmp` は根ではないので、プレビューのチップは出ない。`移動を依頼` は移送をエージェントに頼むが、移送はエージェントの裁量で、断られる・別の場所へ置かれる・名前だけでは移動元を取り違えることがある。モックを 1 つ見るたびに移送の往復が入るのは、モックを見る手段を補うための仕組みとしては重い。

## Decision

### 根

- 追加根の既定を `/tmp` にする。根の番号は 0 がチェックアウト、1 が `/tmp`、2 以上が `HWC_PREVIEW_ROOTS` の順。チェックアウトを持たないペインでは `/tmp` が 0 番
- `HWC_PREVIEW_ROOTS`（`:` 区切りの絶対パス）は残す。既定の根に足す口で、置き換える口ではない
- パスは literal な `/tmp`。`TMPDIR` も `os.tmpdir()` も見ない。エージェントが本文に書くのは `/tmp/...` で、プロセスの環境で変えても一致しない
- 表記違いの同じ実体は 1 回だけ試す。根の番号は先に来たものを保つ
- 根を外す口は作らない（YAGNI）
- 検出と配信の規則は ADR 0051 のまま。実在確認、`realpath` による根の外の拒否、allowlist、`nosniff`、sandbox は変えない

### 画面

- `移動を依頼` のボタンと、依頼文（`moveRequestText`）を消す。押した結果が移送に依存する以上、hwc が次の一手を約束できない
- 1 行の案内は残す。文言は「チェックアウトと `/tmp` の外にあるため、プレビューできません」。次の一手は会話で直接指示する
- ADR 0065 は「案内だけ出してボタンを置かない」を却下した。当時は根を広げず、案内の先が移送しかなかったため。`/tmp` を許した後は、案内が出るケース自体が少数になり、次の一手も 1 文で伝えられる

## Consequences

- エージェントが `/tmp` に書いた HTML と画像は、設定なしでチップとプレビューになる。既存の会話も、取り直せば出る
- `/tmp` の配下を、LAN の誰でも既知のパスで読める。認証は無い（[ADR 0010](0010-lan-access.md)）。一覧は取れず、allowlist の形式だけで、根の外は `realpath` で拒否する。パスを知っている人が対象
- モックが `/tmp` 内の隣接ファイルを相対参照で読める。`/tmp` は共用なので、他のプロジェクトの一時ファイルも対象になり得る
- 相対名はチェックアウト → `/tmp` の順に解決する。`/tmp/<name>` が実在すると、本文の `mock.html` がそちらを指すことがある
- `/tmp` は再起動で消える。残す価値のあるモックを `.artifacts/` に置く運用は変わらない
- 根の番号が 1 つずれる。保存しているのは会話のスナップショットだけなので、取り直せば直る
- 案内が出るのは、チェックアウトと `/tmp` の外に書いたときだけになる
- `HWC_PREVIEW_ROOTS` を使っている環境では、追加根の番号が 1 つ後ろへずれる

## Alternatives

- **`/tmp/hwc-preview` を規約にする**: エージェントに置き場所を守らせる必要があり、hwc を起動していないペインと過去の会話には効かない（ADR 0065 の Context と同じ理由）
- **検出済み HTML のディレクトリだけを動的な根にする**: 露出は最小になるが、ADR 0051 の「根の番号は設定から決まる」設計を崩し、`../font.woff2` のような親ディレクトリの参照も壊れる
- **案内ごと消す**: `/tmp` の外に書いたときに、チップが出ない理由が画面から消える（ADR 0065 が直した欠陥へ戻る）
- **根を外せる環境変数を足す**: `/tmp` を外したい利用者がいるかは未確定。既定と追加の 2 経路で足りる
- **`/tmp` の配信で `json` を除く**: モックがデータを `fetch` する形を壊す。同じ URL の意味が根によって変わるのも避けたい
