# ADR 0047: 一覧のワークツリー見出しに最新 PR のタイトルを出す

- Status: Accepted
- Date: 2026-11-08

## Context

Herdr が作るワークツリーの名前とブランチはランダムで、hwc の一覧もその名前をそのまま出している。作業を始めた直後は覚えていても、PR を作ったあとやレビューを待つ間に、どのワークツリーが何のタスクだったかを名前から思い出せない。

[ADR 0017](0017-active-agents-view.md) のアクティブ帯は名前とブランチ、[ADR 0019](0019-pane-row-content.md) のツリーは名前とリポジトリ・ペイン数を持つ。どちらもタスクの内容は持たない。[ADR 0043](0043-pane-head-pull-request.md) は PR の番号を 1 枚表示の見出しにだけ出し、取得も open の PR に限っている。一覧の見出し行は展開や移動のボタンなので、その中にリンクを置けないことも、一覧に PR を出さなかった理由の 1 つだった。

Herdr には `workspace.rename` と `workspace.report_metadata`（表示用 token）がある。ただし rename は TUI 側の表示名も変え、ランダム名で TUI と対応付けている今の使い方から外れる。metadata token は hwc がまだ読んでおらず、Herdr の再起動で消える。LLM の要約はプロバイダーと API キーの設定、会話の外部送信、コスト、失敗時のフォールバックを別に設計する必要がある。最初のユーザー発話は代表ペインの選び方と compaction 後の欠落を扱う必要がある。

PR のタイトルは、タスクが確定して PR を作った時点で必ず存在する。`gh` の経路とキャッシュは既にあり、PR の番号と URL も取得している。

## Decision

- 概要はブランチの最新 PR のタイトルにする。state は問わない。merge 後もワークツリーが残ることがあり、概要は PR の状態ではなくタスクの識別に使うため
- `gh pr list --head <branch> --state all --limit 1 --json number,url,title,state` で引く。既定の並びは作成日時の降順なので、先頭を最新とする
- `PullRequest` は `{ number, url, title, state }` にする。title は空白を畳んで空を拒否し、state は `OPEN` / `MERGED` / `CLOSED` だけを受け付ける。URL は既存の GitHub pull URL の検証を変えない
- アクティブ帯は、1 行目を PR のタイトル（無ければ名前）と `#123` のチップ、2 行目をブランチにする。名前は帯全体のボタンの読み上げとツリーに残す（2026-11-09 変更）
- チップは `OPEN` と `MERGED` のとき出す（2026-11-09 変更）。`CLOSED` は出さない
  - マージ後もワークツリーは残る。チップを消すと、PR の無い／引けないスペースと見分けが付かず、終わったタスクと作業中のタスクを取り違える
  - merged は success 色にし、番号の手前にマージの記号を置く。色だけに意味を持たせないため、記号と読み上げ（`PR #123（マージ済み）を GitHub で開く`）を併用する
  - GitHub の merged の紫は採らない。アクセントが紫のテーマでは両者が近くなり、テーマごとに新しい色を足して保守することになる。この UI では緑が既に「終わった」を意味しており、意味も揃う
- チップは帯全体の移動ボタンとは別のリンクとして、ボタンの上に重ねる。名前のタップは今までどおり「すべて」のその場所へ移る。リンクは新しいタブで開く
- すべてツリーの見出しは、2 行目を PR のタイトル（無ければ今の `repoName · N ペイン`）にする。merged のときはタイトルの手前にマージの記号だけを置き、番号は帯とメニューに任せる（2026-11-09 変更）。リポジトリ束ねのホストは自分の見出しを持たないため、束の見出しがホストの入口を兼ねる。ホストに PR があればそのタイトルを出し、無ければ今までどおりワークツリー数を出す。ワークスペースメニューに `PR #123 を開く` を足し、こちらは state を問わない。シェルだけのグループは 2 行目を「シェルのみ」にし、右端をシェルの記号にする（2026-11-09 変更、[ADR 0053](0053-all-list-agent-presence.md)）
- 1 枚表示と分割セルのペイン見出しのチップは、[ADR 0043](0043-pane-head-pull-request.md) のまま `OPEN` に限る。同じ PR がセルごとに並ぶ場所なので、merged を足すと終わったタスクの情報で埋まる
- 取得は `GET /api/workspaces/:id/pull-request` のままとし、状態のスナップショットには載せない。[ADR 0043](0043-pane-head-pull-request.md) と同じく、`gh` の待ちを状態の取り直しに混ぜないため
- BFF のキャッシュは既存の 60 秒 / 120 秒を流用する。`refresh=1` のときだけキャッシュを飛ばして引き直し、結果で置き換える
- クライアントは一覧の初回表示で取得し、タブが可視に戻ったとき、直近の完了から 30 秒以上経っていれば `refresh=1` で引き直す。ポーリングはしない。対象のワークスペース集合とブランチが変わったときも引き直す
- PR が無い・取得できないときは今までの表示のままにする。エラーは出さない
- [ADR 0043](0043-pane-head-pull-request.md) の「チップは open の PR だけ」「ペイン見出しにも出す」は残す。この ADR が変えるのは、取得条件を最新 PR に広げることと、一覧の帯・ツリー・メニューにも出すこと

## Consequences

- `gh` が無い・未認証・オフラインの環境では、概要もチップも出ない。既存のチップと同じ依存
- PR のタイトルはリポジトリの規約で英語になる。日本語の概要が必要なら、LLM や最初の発話を別に検討する
- ツリー見出しの `repoName · N ペイン` は、PR がある間はタイトルに置き換わる。リポジトリ名は同じリポジトリを束ねたときの見出しに残り、ペイン数は状態の件数や中身から読める。束の見出しは、ホストに PR がある間だけワークツリー数の代わりにホストのタイトルを出す
- タブに戻ってから最大 30 秒、PR の作成が反映されないことがある。直近 30 秒以内に作った PR は、次の復帰またはリロードまで出ないことがある
- merge 後もタイトルとチップは残り、チップの記号と色でマージ済みだと分かる。ツリーの見出しはタイトルの手前に記号が出る。ペイン見出しのチップは消えるので、PR を開くには一覧のチップかツリーのメニューを使う
- 同じブランチに複数の PR がある場合は、作成日時が最新の 1 件だけを出す。古い open の PR が残っていても、新しい closed の PR が選ばれる
- アクティブ帯はチップのぶん高さが増えることがある。狭い画面ではタイトルとブランチが先に省略され、チップ・件数・上流との差は残る
- PR がある間は帯からワークツリー名が見えなくなる。名前は帯全体のボタンの読み上げ・ツールチップと「すべて」の見出しで読める
- PR のタイトルはタスクの要約ではない。PR を作る前や、タイトルが一般的な場合は、名前だけのときよりはましという程度に留まる

## Alternatives

- **LLM で会話を要約する**: タスクに合った日本語の概要を作れるが、プロバイダーと API キーの設定、鍵の保管、会話の外部送信、コスト、失敗時のフォールバック、誰でも叩ける要約エンドポイントの抑制が必要になる。PR タイトルで足りないと分かってからで遅くない
- **最初のユーザー発話を使う**: PR 前も識別できるが、代表ペインの選び方と、compaction 後に最初の発話がスナップショットから消える問題を扱う必要がある
- **手動で概要を付ける**: 正確だが、ワークツリーを作るたびに入力が要る。保存先も新しく持つことになる
- **Herdr の `workspace.rename` で名前を変える**: TUI と hwc の両方に一度で出せるが、TUI と対応付けるためのランダム名が消える。worktree のフォルダ名・ブランチ名とは別の表示名を持つことにもなる
- **Herdr の metadata token に概要を載せる**: TUI 側にも出せるが、hwc が token を読む契約を足す必要があり、Herdr の再起動で消える
- **open の PR だけを対象にする**: merge 後についても概要を残したい今回の目的に合わない
- **表示中にポーリングする**: 常に新鮮になるが、見ている間ずっと `gh` を起動する。可視復帰と 30 秒の下限で足りる
- **帯のボタンの中にリンクを置く**: 帯全体がボタンなので、入れ子の操作になり押せない。チップを別のリンクとして上に重ねる

## Verification

- unit で、title の正規化、state の受理、不正な title / state の拒否、最新 PR の読み取り、キャッシュの TTL、`refresh` のキャッシュ飛ばしと置き換えを確認する
- 架空 Herdr と架空 `gh` の E2E で、アクティブ帯のタイトルとチップ、merged のタイトルとマージの記号つきチップ、ツリー見出し、メニューのリンク先を確認する
