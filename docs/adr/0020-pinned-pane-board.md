# ADR 0020: スペースを跨ぐペインはピン留めしたボードに並べる

- Status: Proposed
- Date: 2026-11-04

## Context

いまの分割は、選択中ペインが属するタブの兄弟ペインだけを並べる。表示対象は「選択中タブ − 非表示」で導出でき、状態を持たない。広い画面だけで動き、狭い画面では 1 枚ずつ見る。

並行でワークツリーを回すと、見たいペインは同じタブに揃わない。スペース（ワークツリー）を跨いで「いま見たい 3〜4 枚」を並べたいという要求がある。一方、ブラウザタブを複数開く手は、一覧が二重になり、選択の保存（localStorage）も共有されるため中途半端になる。

分割の仕様はまだ ADR / Issue になっていない。ここでは、スペースを跨ぐ並べ方の土台だけを提案し、細部は実装の Issue で詰める。

## Decision

- 複数ペイン表示は「タブの分割」ではなく、HWC ローカルの**ボード**（ペイン ID の集合と順序）として持つ
  - 対象は任意のスペースのペイン。最大 4 枚
  - 広い画面だけ。狭い画面は今までどおり 1 枚ずつ
  - 並べ方は 2 / 3 / 4 枚の固定レイアウト（左右、左 1 + 右 2、2x2）。利用者のドラッグ・リサイズは持たない
  - 順序はピン留めした順。入れ替えは明示操作（メニューの「前へ / 後ろへ」など）で行い、ドラッグは持たない
- ピン留め / 解除は一覧のペイン行から行う。ボードは端末ごとに localStorage へ pane id の配列で保存し、消えたペインは読み込み時に落とす
- ボードは Herdr のフォーカス・タイルを変えない。Herdr の状態を映すだけで、HWC の中だけの見え方
- セル見出しには、そのペインのスペース（ブランチ）を出す。跨げる以上、セルごとの文脈が要る
- タブバーはタブ内のペイン切り替え（ナビゲーション）として残し、ボードのセル一覧とは別物にする
  - 分割トグルは「ボードの表示 / 非表示」に読み替える
  - 既存の「非表示（目のアイコン）」はボードのメンバーシップに置き換え、状態を 1 つ減らす

## Consequences

- 分割の対象が「選択中タブの兄弟」から「ピン留めしたペイン」に変わる。選択中ペインとセルの関係を決める必要がある
- ペインが閉じられたら、そのセルは次回のスナップショットで消える。保存した ID は読み込み時に落とす
- ボードはデスクトップ専用。スマホでは見えない
- ブランチはセルごとに出すことになる。同一スペースのセルが並ぶと重複するが、跨げる以上はセルの文脈として正しい
- タブを切り替えてもボードは変わらない。一覧の選択はナビゲーションに留める
- 2 枚以上のペインを同時に購読するので、出力・会話の取得はセル数だけ並ぶ（今の分割と同じ）

## 未決（実装 Issue で決める）

- 一覧行のピン留め操作の形（行メニューの項目か、行内のトグルか）
- ボード表示中の一覧選択の意味: セルを置き換えるか、移動だけか
- 入れ替えの操作: メニューの前後移動、キーボード、セル見出しのボタン
- 0 枚 / 1 枚のときの見え方、4 枚を超えるときの扱い
- ボードのオン / オフとタブ切り替えの関係
- 保存の掃除（長く使うと ID が溜まる）

## Alternatives

- **タブ内の分割のまま**: 状態を持たず最も簡単。ただしスペースを跨げないので、今回の要求を満たさない
- **自由なドラッグ・リサイズ**: ウィンドウマネージャになる。主端末のスマホでは使えず、デスクトップ専用の複雑さだけが増える
- **ブラウザタブを複数開く**: 一覧が二重になり、選択の保存も共有される。ボードの方が一貫している
- **`active` スコープを拡張する**: 一覧は一覧で、空間的に並べる用途にはならない。ボードは詳細の見え方として分ける
