# ADR 0054: タブのファビコンにスペースの親ペインの状態を出す

- Status: Accepted
- Date: 2026-11-10

## Context

hwc を別のブラウザタブで開いたまま、エージェントの完了や質問に気付きたい。タブタイトルや画面内の通知は、hwc のタブを見ていない間は見えないか、見ていても気付きにくい。ブラウザのタブストリップは favicon を常に出すため、状態を色の点で示せれば、hwc のタブに戻る前に変化が分かる。

スペースには複数のエージェントがいることが多い。impl と review の両方が終わったときに完了としたいが、Herdr の `workspace.agent_status` は状態の優先順で畳む集約値であり、`done + idle` でも `done` になり得る。スペースの集約値をそのまま「全員完了」として使うことはできない。

一方、最初に作った左端のペインを orch または impl として、そこから子のエージェントへ指示を出す運用が多い。親が終わったとき、または親が質問で止まったときが、利用者にとって意味のある区切りになる。子の `done` を全部集めるより、親の状態を 1 つ見る方が運用に合う。

## Decision

### 親ペイン

- スペースごとに、左端のタブから順に、最初の `agent !== null` のペインを親とする。シェルは飛ばす
- Herdr の snapshot には作成順が無いため、一覧の並び（左端）で代用する。既存の `defaultPaneOf` と同じ順序を使う
- 親を手で選ぶ設定は持たない

### ファビコンの状態

- **赤**: 親・子を問わず、どこかのエージェントが `blocked`
- **水色**: 赤がなく、どこかのスペースの親が `done`
- **黄**: 赤も水色もなく、どこかのエージェントが `working`
- **点なし**: それ以外

優先度は 赤 > 水色 > 黄 > なし。完了は親だけで見る。子の `done` を混ぜると、impl だけ終わった段階でスペース全体が完了に見える。赤と黄は子も含める。子の質問や作業は、親の状態に関係なく拾う必要がある。

### 表示

- favicon だけを変える。タブタイトル、右下の知らせ、プッシュ通知は持たない
- 状態の点は、既存のファビコンと同じ角丸の背景とロゴの右下に置く。画像を状態ごとに用意せず、SVG 文字列を `data:image/svg+xml,` の URL にして `link[rel="icon"]` の `href` を差し替える
- 色はファビコン専用に定義する。UI の `--color-attention`（オレンジ）と `--color-success`（緑）をそのまま使うと、指定の黄・赤・水色にならない
- SVG の `viewBox` は四方に 1 単位の透明な余白を取り、図形を 0..24 に収める。Windows Chrome の 125% 表示で端の画素が反対側へにじむのを防ぐ
- HTML には点なしの SVG を最初から置く。スクリプトが動き出したら、SVG の `href` を状態に合わせて更新する
- PNG の `rel="icon"` は、ブラウザが PNG を選ぶと SVG の更新が反映されないため、スクリプトの開始時に取り除く

### 親マーク

- ファビコンがどのペインを見ているか分かるよう、一覧（アクティブ / すべて）のペイン行と詳細のペインタブに、王冠の SVG を添える
- 親マークは、そのスペースにエージェントが 2 枚以上いるときだけ出す。1 枚だけなら親が自明で、印を増やす意味がない。シェルは数えない
- マークは状態記号でも操作でもない。`--color-secondary` の補助色に置き、`title` と読み上げでは「親ペイン」と伝える
- ファビコンとマークは同じ親の選択関数を使う。表示と状態がずれないようにする

## Consequences

- 親が `done` の間は、子が `working` でも水色になる。親が終わったスペースを探すための表示なので、子の作業中は黄に落とさない
- 親の `done` は Herdr の未読状態。親を開いて離れると `idle` になり、水色は消える。通知として見たら消える扱いになる
- 親が orch なら、impl と review の両方が終わったときに親が `done` になる。親が impl なら impl の完了だけを見る。どちらを親にするかは、左端に置く運用で決まる
- 子が `blocked` の場合は赤になる。親が処理中の質問でも赤くなるが、質問を見落とすよりは良い
- 同じスペースに複数の組を置き、片方だけ終わった場合、その組が親でなければ水色にならない。組を分けたいときはタブを分ける
- 左端が親という規約に依存する。最初のエージェントが子の場合は、その子が親として扱われる。親を明示したいときは別の仕組みが要る
- Pi のフォルダ信頼確認のように Herdr が `blocked` にしない確認は、赤くならない
- ファビコンの更新は、hwc のタブがブラウザで生きている間だけ。iOS のバックグラウンドタブは凍結され、デスクトップ Chrome の別タブのように常時更新される保証はない
- タブタイトルは変えない。タイトルを目印にしている利用者への影響はない

## Alternatives

- **スペース内の全エージェントが `done`**: impl と review の両方を見られるが、同じスペースに idle のエージェントが残ると完了にならない。子の状態を全部集約する必要があり、親の判断を二重に持つ
- **どこか 1 ペインでも `done`**: 実装は小さいが、一方だけ終わった段階で完了に見える。子の作業中でも水色になる
- **Herdr の `workspace.agent_status` を使う**: `done + idle` を `done` と誤判定する。全員完了の意味にならない
- **タブタイトルに状態を出す**: 文字で伝わるが、タイトルは長いスペース名で切れ、favicon のように常時見えるとは限らない。今回はファビコンだけにする
- **右下の知らせを併用する**: 画面を見ている間しか見えず、通知の設計と状態を持つ必要がある。別の課題とする
