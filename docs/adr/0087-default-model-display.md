# ADR 0087: 既定モデルで起動したペインのモデル表示は、チャット画面を開いたときに読む

- Status: Accepted
- Date: 2026-11-15
- Revises: [ADR 0033](0033-launch-model-before-first-message.md) の「モデル未指定の場合は預からない」と「最初のメッセージまでモデル名が出ない」
- Amended by: [ADR 0091](0091-empty-session-model-display.md)

## Context

[ADR 0033](0033-launch-model-before-first-message.md) は、起動時に選んだモデルだけを表示用に預かった。モデル未指定（デフォルトモデル）で起動すると、pi が最初のメッセージまでセッションにモデルを書かないため、入力欄のモデルと effort が空のままになる。新しいペインのダイアログの初期値は「デフォルトモデル」なので、hwc から作るペインの多くがこの状態になる。

既定値は pi 本体が設定から解決する。起動時に BFF が同じ解決を待つと、ペインの作成が 1〜2 秒遅くなる。値は会話が始まるまでの表示にしか使わない。

## Decision

- モデルを指定せずに hwc から pi を起動したとき、BFF はペイン id に「既定モデルで起動した」ことだけを預かる。起動時に pi へ問い合わせない。預かりは `agent.start` の前（ペインがエージェントとして見える前）に置き、起動に失敗したら捨てる（初回の信頼確認待ちは起動失敗として扱わない）
- `GET /api/panes/:id/default-model` を足す。ペインが pi で会話を持ち、預かりがあるときだけ、その cwd で `pi --offline --mode rpc --no-session` を起動して `get_state` を読み、`{ model, effort }` を返す。モデルは `model.id`、effort は `thinkingLevel`（推論しないモデルは `null`）。cwd はペインから引く
- 預かりが無い場合（モデル指定の起動、他エージェント、hwc 以外からの起動、BFF 再起動後）は `{ model: null, effort: null }` を返す。既定モデルを推測して、実際と違うモデルを出さない
- 解決は成功した値だけをペイン id ごとに保持し、同じペインの同時要求は 1 つに畳む。値と解決中の問い合わせは起動世代に紐づけ、終了・再起動後に古い問い合わせが返っても新しい世代の値や `loading` を変えない。失敗は保持せず 502 `default_model_unavailable` を返す。会話にモデルが載ったとき、`close` / `exit` が成功したときに捨てる。永続化しない
- クライアントは、チャット画面を開いていて、会話スナップショットにモデルも effort も無く、起動時の指定も無いときに 1 回だけ読む。読んでいる間はモデル名と effort の位置にスケルトンを出す。スケルトンは短い遅延の後ろに置き、預かりの無いペインで一瞬だけ出るのを避ける。会話にモデルが載ったらクライアントの値は使わない
- 失敗や取得できない場合は何も出さない。再試行の UI は置かず、ペインを開き直したときにまた読む

## Consequences

- 既定モデルで起動したペインでも、最初のメッセージの前にモデルと effort が見える。ペインの作成は遅くならない
- 既定値はペインの cwd で新しく起動した pi が解決する。TUI で動いている実際のプロセスと、モデル・effort・拡張の状態が完全に一致する保証はない。送信後はセッションの値に置き換わる
- 最初のメッセージの前に TUI でモデルを切り替えても、表示は起動時の既定のままになる（ADR 0033 と同じ制約）
- hwc 以外から起動したペインと、BFF の再起動を挟んだペインは対象外。モデル指定の起動と区別できず、既定を出すと実際と違う値を出すおそれがあるため
- pi 以外のエージェントには広げていない。広げるときは、それぞれの既定の読み方と、モデル未指定の起動をどう区別するかを決める
- 表示用の問い合わせが増える。ペインを開くたびに cwd を引き、預かりが無ければ何も起動しない。預かりがあっても解決は 1 回だけ
