# ADR 0106: シェルのペインにもファイルツリーを出し、フォルダから新しいスペースを作る

- Status: Accepted
- Date: 2026-11-20
- Revises: [ADR 0090](0090-pane-file-tree.md) の「チャットを持たないシェルのペインには出さない」。[ADR 0038](0038-create-worktree.md) の「一般のスペース作成は持たない。例外は `worktree.create` に限る」

## Context

ファイルツリーは、チャットのあるペインにしか出していなかった（ADR 0090）。開いたファイルを配る `/preview` と `/files` がペインのチャットを要求するためで、配信を全ペインへ広げるかは別の判断に回していた。

しかし、ツリーを地図として見たいのは会話中だけではない。エージェントを起動する前のシェルのペインで、チェックアウトの構造を見ながら作業の起点を決めたい。たとえばモノレポのサブプロジェクトを選び、そこを作業ディレクトリにした新しいスペースでエージェントを起動する、という流れである。

この流れには、スペースを作る操作が欠けている。hwc が作れるスペースはワークツリーだけで（ADR 0038）、任意のディレクトリを起点にしたスペースは Herdr TUI に戻らないと作れない。Herdr には `workspace.create`（`cwd` / `label` / `focus`）があり、作ったスペース・タブ・root pane を返す。

## Decision

### シェルのペインのツリー

- ファイルツリーの入口・一覧・プレビューを、チャットの有無に関わらず全ペインに出す。`/tree`・`/preview`・`/files` のチャット条件を外す。根はこれまでどおりペインのワークスペースのチェックアウトで、配信の allowlist と `.env` ブラックリストも変えない
- シェルのペインでも、会話のペインと同じく、狭いセルでは端末出力の上に重ね、広いセルでは並べる
- 行を入力欄へドラッグする操作（[ADR 0095](0095-file-tree-drag-to-composer.md)）は、会話のペインに限ったまま。シェルの入力欄へ運ぶ要望は、まだ無い

### フォルダから新しいスペース

- ツリーで展開できるフォルダの行の右端に「新しいスペース」のボタンを置く。ポインタの画面では、行に乗ったときかフォーカスがあるときだけ出す。触れる画面では常に出す（ペインの「…」と同じ規則）
- 押すと作成ダイアログ（[ADR 0027](0027-new-pane-agent.md)）を「新しいスペース」として開く。説明に起点のフォルダを出し、ペイン名・エージェント / シェル・モデル・effort はワークツリーと同じに選ぶ
- `POST /api/panes/:id/create-space` を足す。body は `{ path, name? }` で、`path` はツリーの根からの相対パス。ツリーの一覧と同じく、根の配下にある `.git` 以外の実在するディレクトリだけを受ける。絶対パスは受け取らない（[ADR 0041](0041-agent-message-images.md)）
- BFF は `workspace.create` に `{ cwd: <実体の絶対パス>, label: <フォルダ名>, focus: true }` を送る。スペース名を Herdr の既定に任せると、同じリポジトリの別のスペースと見分けが付かない場合がある
- root pane の名前付けと、エージェントの起動はワークツリーと同じ経路を使う。BFF は作成と名前付けまでで、起動はペインがスナップショットに現れてからクライアントが頼む（[ADR 0084](0084-launch-after-create.md)）
- 失敗の写し方:
  - ペインが無い → 404 `pane_not_found`。チェックアウトが無い → 404 `no_checkout`。ディレクトリが無い・根の外・`.git` → 404 `not_found`
  - body が不正 → 400。Herdr の `invalid_params` / `invalid_request` → 400
  - それ以外の Herdr の失敗と、期限切れ・切断 → 502 `herdr_unavailable`。作成できたかが分からないので、ダイアログは再送させず「閉じる」だけにする
  - 名前付けだけの失敗 → 502 `pane_rename_failed`（部分成功）。スペースは残るので起動へ進む

## Consequences

- シェルのペインでもツリーとプレビューが使える。認証なし LAN で列挙と配信ができるペインが、チャットのあるペインから全ペインへ広がる（[ADR 0010](0010-lan-access.md)）。ただし根はどのペインでもワークスペースのチェックアウトで、見えるファイルの範囲は同じリポジトリの中から広がらない
- フォルダを選んで、そこを作業ディレクトリにしたスペースとエージェントを、スマホから 1 回のダイアログで作れる
- スペースの作成は Herdr の既定のタブ・レイアウトに任せる。タブの作成・スペースの複製は持たないまま
- 根そのもの（チェックアウトの直下）は行が無いので、ここからは選べない。同じ場所のスペースは既にある
- 作ったスペースが Herdr の linked worktree の判定にどう載るかは、Herdr の cwd の解決に任せる。hwc は git の種別をチェックアウトから読む（[ADR 0075](0075-git-kind-from-checkout.md)）

## Alternatives

- **一覧だけをシェルのペインに出し、プレビューは会話のペインに限る**: 配信の範囲を広げずに済む。ただ、ツリーの行を押しても何も起きないペインと起きるペインが混ざり、同じ部品の振る舞いがペインの種類で変わる
- **スペースではなくタブを作る**: 同じスペースの中に収まるが、タブの cwd は Herdr の `terminal.new_cwd` に従い、フォルダを起点にできない
- **作成先をパス入力で決める**: ツリーを見ながら選ぶ流れから外れ、スマホで絶対パスを打たせることになる。クライアントに絶対パスを渡さない契約（ADR 0041）とも合わない
- **スペース名を Herdr の既定に任せる**: ワークツリーでは Herdr の既定（フォルダ名）がそのまま読めるが、サブディレクトリのスペースでは既定が分からない。フォルダ名を明示する
