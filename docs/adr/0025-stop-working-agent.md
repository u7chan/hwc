# ADR 0025: 実行中のエージェントは入力欄の停止ボタンから Esc で中断する

- Status: Accepted
- Date: 2026-11-04

## Context

送信したメッセージへの返答が始まると、hwc の送信ボタンはスピナー付きで無効になる。返答を待つ間、利用者は入力欄へ追加の指示を送れるが、今のターン自体を止める手段は無い。止めるには Herdr TUI に戻るか、ペインを閉じるしかなく、後者は開いていた作業を失う。

Herdr の `pane.send_keys` は `{ pane_id, keys }` を受け、`esc` を Escape として扱う。pi / Claude Code / Codex CLI / opencode の 4 つは、既定の Esc で実行中のターンを中断する。入力欄に文字がある状態の送信は、4 つとも現在のターンへの追加指示（steering / queue）として既に機能している。

## Decision

- 入力欄のボタンは 1 つを兼ねる。`agentStatus === "working"` かつ入力が空のときは停止ボタン、それ以外は送信ボタンにする
  - 入力が空とは、下書きが `trim()` で空、添付なし、引用なし、チップなしのすべてを満たす状態
  - 文字・添付・引用が入れば送信ボタンに戻る。実行中の送信は追加指示として既存の input 経路へ流す
  - 停止ボタンは pi / claude / codex / opencode の既知のエージェントだけに出す。シェル、generic、未知のエージェントは対象外
- 停止は Herdr の `pane.send_keys` に `{ pane_id, keys: ["esc"] }` を送る。文字は送らない
- BFF に `POST /api/panes/:id/stop` を足す。`application/json` 以外は 415、スナップショットが無ければ 502、BFF の状態にペインが無ければ 404。成功は `{ ok: true }`
- BFF はスナップショットの `agentStatus` が `working` のときだけ Esc を送る。止まっているペインへの Esc は入力欄やダイアログを閉じる副作用があるため、画面が古いだけの再クリックは成功として扱い、Herdr へは送らない
- 停止リクエストの間だけクライアント側でスピナーを出す。成功後は楽観的に状態を変えず、SSE の `agentStatus` 更新を待つ
- 停止リクエストは 8 秒で打ち切る。失敗時はメッセージ領域の下端に「停止できませんでした」を出し、停止ボタンへ戻して再試行できるようにする
- 確認ダイアログは挟まない。停止は送信済みメッセージを消さず、同じ入力からやり直せる
- 送信済みメッセージと送信中バブルは停止後も残す。停止したターンの assistant メッセージは hwc の会話に出ないが、hwc 側で履歴を書き換えない
- ブラウザの Esc キー、一覧からの停止、全ペイン一括停止、停止の取り消しは持たない

## Consequences

- 停止は Esc を 1 回送るだけで、エージェントが実際に止まったかは保証しない。状態は Herdr の `agentStatus` を正とする
- Claude Code などでダイアログが開いていると、1 回目の Esc はダイアログを閉じる方が優先される。停止ボタンは残るので、利用者はもう一度押せる
- Herdr の状態反映が遅れると、停止成功後も一時的に停止ボタンが残る。BFF の停止は冪等なので、再クリックしても Esc は送られない
- Esc はエージェントごとの TUI 状態に依存する。カスタムキーバインドや将来の CLI 変更で中断キーが変われば、この前提を見直す
- 停止ボタンと送信ボタンは同じ位置・同じ面を使う。アイコンと `aria-label` で動作の違いを示し、入力の有無で意味が変わることは placeholder や会話の状態から読み取れるようにする
- 停止の成功を通知しない。返答の進行表示が消えることで伝わる。失敗だけを notice で出す

## Alternatives

- **送信 HTTP を abort する**: 送信後のターンは止まらず、ユーザーの目的を満たさない
- **ペインを閉じる**: 作業が失われ、止める手段としては重すぎる。close は別の操作として残す
- **常に停止ボタンを出す**: 入力中の送信（steering）ができなくなる。入力がある間は送信を優先する
- **確認ダイアログを挟む**: 停止は取り消し可能な操作ではなく、確認の間にもエージェントが進む。1 タップで止められることを優先する
- **停止後に「停止しました」を出す**: 実際に止まったかは Herdr の状態で決まる。成功の notice は状態と食い違い得る
