# ADR 0059: エージェント終了後はシェルに戻った時点で旧画面を消す

- Status: Accepted
- Date: 2026-11-10

## Context

[ADR 0029](0029-preserve-last-pane.md) の「エージェントを終了」は、スペースの最後のペインを残すために `/quit` を送るだけで、ペインはシェルのまま残る。ただし端末には終了したエージェントの TUI の最後の画面が残る。hwc は会話を持たないペインを端末出力として表示するため、終了後はその画面がシェルの出力として見え、エージェントがまだ動いているように読める。

同じく終了したペインでは、クライアントが最後に読んだ会話のスナップショットを持ち越していた。入力欄のモデル名とコンテキストは、ペインが会話を持つかではなく、最後に読んだ古いスナップショットから作っていたので、シェルに戻っても agent の情報が出続けた。

端末の画面は Herdr が持つ。hwc の表示だけを隠しても、次の `pane.read` で同じ画面が戻る。終了したエージェントの画面を残す理由は無いが、クラッシュや TUI からの終了では最後の画面が原因の手がかりになるので、すべてのエージェント消滅で消してよいわけではない。

## Decision

- hwc からの exit 要求が成功したとき、ペイン id と終了前の agent を覚える。次の状態公開でそのペインの agent が消えていたら、`pane.clear` を 1 回だけ送り、シェルのプロンプトだけの画面にする。ペインごと消えた場合、別のエージェントに変わった場合、上限（30 秒）を過ぎた場合は送らない
- 消せるかどうかは状態の変化で判断する。exit の応答は `/quit` を送れたことしか保証しない（ADR 0029）
- 対象は hwc から終了したペインだけにする。Herdr TUI からの終了とクラッシュは画面を残す。どちらも最後の画面を読む価値がある
- `pane.clear` の失敗は無視する。終了そのものは済んでおり、画面が残るだけなので再試行は求めない
- クライアントは `pane.chat` が false になったら最後の会話スナップショットを捨てる。モデル名・コンテキスト・会話はシェルのペインへ持ち越さない

## Consequences

- 終了後に残るのはシェルのプロンプトだけになる。opencode の `Continue` 行のような終了時の案内も消えるので、再開用のコマンドをコピーしたい場合は終了前に読む必要がある
- `pane.clear` は画面とスクロールバックを消す。同じペインのシェルでエージェント起動前に流していた出力も消える
- 状態の公開から消えるまでは、最後に読んだ古い画面が最大で出力ポーリング間隔（2 秒）だけ見える
- exit 要求から 30 秒間、状態の公開ごとにペイン 1 つ分の照合が残る。要求は通ったのにエージェントが終了しない場合も、同じだけ待つ
- 終了したエージェントの会話は、シェルの入力欄からモデル名とコンテキストが消えるだけでなく、会話ビューにも残らない。ペインを開き直しても端末出力になる

## Alternatives

- **agent が消えるすべての遷移で消す**: クラッシュや TUI からの終了でも最後の画面を消してしまい、原因を読めなくする
- **クライアントだけで古い画面を隠す**: 次の `pane.read` で同じ画面が戻る。開いているクライアントと開いていないクライアントで見え方が変わる
- **`/quit` の直後に消す**: エージェントが終了する前に消すことになり、TUI が描き直す。終了しない場合も画面だけ失う
- **クライアントが状態の遷移を見て消す**: 画面を開いている間しか動かず、再読み込みやスリープを挟むと遷移を取りこぼす
