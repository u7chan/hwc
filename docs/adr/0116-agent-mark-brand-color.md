# ADR 0116: エージェントのマークはブランド色で描き、色は 1 か所で決める

- Status: Accepted
- Date: 2026-11-21
- Amends: [ADR 0085](0085-settings-index.md) の「行のアイコンは枠なしの 20px、色は補助文字と同じにする」

## Context

エージェントのマーク（Claude のオレンジなど）は「どのエージェントか」を示す記号で、状態でも選択でもない。ところが色は面ごとにばらついていた。一覧の行・入力欄のチップ・作成ダイアログのカードは Claude だけブランド色だったが、設定の行とペイン見出しは補助文字の色のままだった。同じマークが、左の一覧ではオレンジ、設定ではグレーになる。

ADR 0085 は設定を 2 段にしたとき、行のアイコンの色を補助文字と同じに決めた。当時マークに色を付ける面は無く、設定の一覧は「読む画面」としてアイコンを主張させない判断だった。その後、一覧・入力欄・ダイアログでマークにブランド色が付き、設定だけが取り残された。

色の定義も 3 つの CSS に散っていた（`list.css` / `input.css` / `choice.css` の `[data-agent="claude"]`）。面が増えるたびに同じルールを書き足す形で、実際に 2 面が漏れていた。

## Decision

- エージェントのマークの色は `marks.css` の 1 か所で決め、一覧の行・ペイン見出し・入力欄のチップ・作成ダイアログのカード・設定の行が同じ値を使う
- ブランド色を使うのは Claude だけにする。Codex / OpenCode のマークはモノクロが公式で、Pi のマークは 3 色（コーラル・青・黄）なので、1 色に潰すとブランド色を作ることになる。どちらも補助アイコンの色に置く
- 選択中・現在地は面と枠と文字で示し、マークの色では示さない。設定の左の列で現在地の行も、面と名前は現在地の色、マークはブランド色のままにする
- 設定の行のアイコンの寸法と枠は [ADR 0085](0085-settings-index.md) のまま（枠なしの 20px）にする。変えるのは色だけ

## Consequences

- 設定の行でも Claude だけ色が付く。ADR 0085 の「状態はアイコンではなく値の側で示す」は変わらない。マークは状態ではない
- マークの色は、選択の色（accent）と同じ画面に出る。選択は面と文字で読めるので、マークがブランド色でも現在地は分かる
- テーマごとの値は `--color-agent-claude` が既に持つ。ブランド色のあるエージェントを足すときは、20 テーマ分の値と `marks.css` の 1 行、`theme.test.ts` の `PALETTE_TOKENS` が要る
- Pi を単色で色付けしたくなったら、3 色のロゴを 1 色に潰すのではなく、3 色のマークとして描き直すかを先に決める

## Alternatives

- **設定の行だけ ADR 0085 のまま補助文字の色にする**: 同じマークが画面によって違う色になり、利用者は別の意味を読み取る
- **すべてのエージェントにブランド色を足す**: Codex / OpenCode はモノクロが公式、Pi は 3 色。ブランド色を持たないマークに色を作ることになる
- **マークを常に accent にする**: エージェントの種類と、選択・現在地の区別が付かなくなる
