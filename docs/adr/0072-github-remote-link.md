# ADR 0072: スペースの Git アイコンから GitHub のリポジトリを開く

- Status: Accepted
- Date: 2026-11-10

## Context

ブランチは一覧とチャット見出しに出ているが、GitHub のリポジトリを開く手段は PR のチップがあるときだけだった。PR が無いブランチや、PR を作る前でも、CI・コミット・ファイルを見たい。リモートの URL は `gh` を使わず、ローカルの remote 設定から読める。

[ADR 0048](0048-git-remote-sync.md) は、上流がある間だけ ↑↓ を出し、その表示がスペースメニューの入口を兼ねると決めた。上流が無い worktree ではツリー見出しの「…」が入口になるが、アクティブ帯には入口が無い。チャット見出しも上流が無いとスペースメニューを開けない。

先頭のアイコンは「非 git / リポジトリ / linked worktree」の種類を表している。GitHub アイコンに置き換えると種類の区別が消え、リモートの有無でアイコンの意味が変わる。ツリー見出しではアイコンが開閉ボタンの中にあり、リンクにすると開閉と遷移が混ざる。右の「…」はペインメニューなので、Git 関連の項目を混ぜるとペインの操作とスペースの操作の区別が崩れる（[ADR 0034](0034-remove-worktree.md)）。

## Decision

- `GitSync` に `repoUrl: string | null` を足す。BFF は `git remote -v` を読み、origin を優先し、origin が GitHub でなければ他のリモートから最初の GitHub URL を選ぶ。`https://github.com/<owner>/<repo>` に正規化する。GitHub 以外、ローカルパス、サブパス付き URL は `null`。既存の 10 秒キャッシュに載せる
- スペースメニューに「リポジトリを GitHub で開く」を足す。PR リンクの手前、同じ区切りに置く。`repoUrl` が無ければ出さない。新しいタブで開く
- ツリー見出しとアクティブ帯の先頭アイコンをスペースメニューのボタンにする。アイコンの枠は今までと同じ 32px、タップ領域は 44px。アイコンの glyph は種類のまま（GitHub アイコンにしない）
- 上流との差は、0 でない側だけを `↑N` / `↓N` のラベルで出す。押せない。ツリー見出しでは右端、アクティブ帯ではブランチ行。上流が無い・0 のときはラベルを出さない。上流の有無にかかわらずアイコンからメニューを開ける
- ツリー見出しの「…」と GitStatus の出し分けをやめ、アイコン一本にする。リポジトリ束ねの見出しは、本体（host）があるときだけ host のメニューを開く。本体が無い束ね見出しはメニューを持たない（各 worktree の見出しから開く）
- モバイルのチャット見出しでは、ブランチ＋↑↓をスペースメニューのボタンにする。上流が無いときはブランチ＋▾だけ。右の「…」はペインメニューのまま
- PC のチャット見出し（1 枚表示）では、空いているところに `worktree.repoName` を出す。`repoUrl` があればリポジトリトップへのリンク、無ければ文字だけ。狭い画面は今までどおりブランチ、分割セルはペイン名
- ペインメニューには Git 関連を出さない
- リポジトリのリンク先はトップだけにする。ブランチページは upstream の有無や名前の一致に依存し、未 push で 404 になるため

## Consequences

- worktree でも upstream が無ければ、ツリー見出し・アクティブ帯・モバイルのチャット見出しからスペースメニューを開ける。リポジトリが GitHub なら、そこからリポジトリトップへ行ける
- 上流との差が 0 のときは数字が出ない。これまで `↑0 ↓0` がメニューの入口を兼ねていたが、入口はアイコン／ブランチに移る。同期していることは数字の不在で表す
- 先頭アイコンは常に押せる（`workspaceId` のある見出し）。リモートが無い Git でもメニューは開けるが、リポジトリの項目は出ない。非 git のスペースも同じアイコンでメニューを開ける
- ツリー見出しの右端から「…」が消え、アイコンとブランチに入口が移る。アイコンのホバー／フォーカスで押せることを示す
- PC のチャット見出しにリポジトリ名が出る。GitHub 以外のリモートやリモート無しではリンクにならない
- リポジトリの URL は 10 秒キャッシュ。リモートを変えた直後は最大 10 秒古い
- マルチリモートでは origin を優先する。origin が GitHub でない場合だけ他の GitHub リモートを使う。fork で upstream だけ GitHub の場合は upstream が選ばれることがある
- ブランチの長押し選択は、モバイルのチャット見出しではスペースメニューに変わる。ツリーのペイン行では今までどおり選択できる
- リポジトリ束ねの見出しに本体が無い場合、その見出しのアイコンは押せない。worktree の見出しから開く

## Alternatives

- **先頭アイコンを GitHub アイコンに置き換える**: 種類の区別が消え、リモートの有無で意味が変わる。ツリーでは開閉ボタンの中にリンクを入れることになる
- **「…」ボタンを常設する**: 入口は明示的だが、行の右側が増え、アイコンは押せないまま
- **ブランチを直接 GitHub のリンクにする**: 未 push や upstream の名前違いで 404 になる。メニューを挟めばトップへ確実に行ける
- **ペインメニューにリポジトリリンクを足す**: モバイルのチャットからは最短だが、右の「…」に Git 関連が混ざる。[ADR 0034](0034-remove-worktree.md) の分離を崩す
- **ブランチページへリンクする**: upstream の有無と名前の一致に依存する。トップだけにすれば失敗しない
- **gh で URL を引く**: ネットワークと認証に依存する。ローカルの remote 設定で足りる
- **アクティブ帯の上流が無いときに「…」を足す**: 入口は増えるが、アイコンを入口にする方が一貫する
