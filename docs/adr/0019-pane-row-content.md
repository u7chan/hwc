# ADR 0019: 一覧のペイン行は名前とブランチで組む

- Status: Accepted
- Date: 2026-11-03

## Context

ツリーのペイン行は、1 段目に端末タイトル、2 段目にペイン名（ラベル）を出していた。端末タイトルはエージェントの種類ごとに同じ値（`π - <repo>` など）になるため、同じリポジトリのペインが並ぶと 1 段目が全部同じ文字列になり、どの行かは 2 段目のラベルでしか分からなかった。また、どのブランチで動いているかを見る手段が無く、ワークツリーを並行で回していると端末で `git status` を打つ必要があった。

## Decision

- 1 段目はペイン名（`label` → 無ければエージェント種別 → 端末タイトル → 最後にペイン ID）。端末タイトルは詳細ヘッダに残す
- 2 段目はブランチ名。取得できない（git 管理外）ときは 2 段目を出さない
- ブランチはワークスペース（worktree）の属性として扱い、同じワークスペースの行は同じ値を出す。Herdr の snapshot には無いので BFF が読む
  - 読む場所は `worktree.checkout_path`、無ければ最初のペインの cwd（Herdr がワークツリーとして扱っていない git リポジトリがある）
  - `.git` が見つかるまで親をたどる（cwd がサブディレクトリのことがある）。リンクワークツリーの `gitdir:` も追う
  - ブランチ切替のイベントは無いので、短い TTL で読み直す
- 副題を持たない行は、行の高さの中で縦中央に置く
- 1 枚表示の詳細ヘッダでは、一覧が隠れる狭い画面に限り、ペイン名の代わりにブランチを 1 回だけ出す。分割セルと広い画面では出さない（同じ値が並ぶため。2026-11-04 追記）

## Consequences

- ペインがワークスペースのディレクトリ以外へ `cd` している場合、2 段目は実際のブランチと違うことがある（ワークスペース単位の近似）
- ブランチの表示は最大 TTL 秒ぶん古いことがある
- 端末タイトルは一覧から見えなくなる（詳細ヘッダでは見える）
- git 管理外のディレクトリでは 2 段目が無く、行が 1 段になる

## Alternatives

- 行に 3 段目を足す: 高さが増え、狭い画面で一覧が読めなくなる
- 詳細ヘッダにブランチを出す: ブランチはペインではなくワークスペースの属性で、全ペインに同じ文字列が並ぶ
- BFF で `git rev-parse` を叩く: プロセス起動が要る。`.git/HEAD` の読み取りで足りる
