# ADR 0019: 一覧のペイン行は名前とブランチで組む

- Status: Accepted
- Date: 2026-11-03
- Revises: 2026-11-11 に複数スペースを並べるときのセル見出しを追記（[ADR 0058](0058-split-view-tab-history.md)）
- Revises: 2026-11-20 に分割セルの場所チップの左へ作成元のスペース名を足した

## Context

ツリーのペイン行は、1 段目に端末タイトル、2 段目にペイン名（ラベル）を出していた。端末タイトルはエージェントの種類ごとに同じ値（`π - <repo>` など）になるため、同じリポジトリのペインが並ぶと 1 段目が全部同じ文字列になり、どの行かは 2 段目のラベルでしか分からなかった。また、どのブランチで動いているかを見る手段が無く、ワークツリーを並行で回していると端末で `git status` を打つ必要があった。

## Decision

- 1 段目はペイン名（`label` → 無ければエージェント種別 → 端末タイトル → エージェントのいないシェルは `シェル`）
- タブと分割セルの見出しの名前は `label` を先にする。ラベルが無ければ端末タイトル（先頭の `π - ` / `OC | ` は Provider アイコンと重なるので落とす）→ エージェント種別 → エージェントのいないシェルは `シェル` の順。ラベルがあるペインでは端末タイトルを出さない（2026-11-04 追記）
- シェルのペイン ID は詳細ヘッダと読み上げ用の `aria-label` に残し、名前としては出さない（2026-11-08 追記）
- 2 段目はブランチ名。取得できない（git 管理外）ときは 2 段目を出さない
- ブランチはワークスペース（worktree）の属性として扱い、同じワークスペースの行は同じ値を出す。Herdr の snapshot には無いので BFF が読む
  - 読む場所は `worktree.checkout_path`、無ければ最初のペインの cwd（Herdr がワークツリーとして扱っていない git リポジトリがある）
  - `.git` が見つかるまで親をたどる（cwd がサブディレクトリのことがある）。リンクワークツリーの `gitdir:` も追う
  - ブランチ切替のイベントは無いので、短い TTL で読み直す
- 副題を持たない行は、行の高さの中で縦中央に置く
- 1 枚表示の詳細ヘッダでは、一覧が隠れる狭い画面に限り、ペイン名の代わりにブランチを 1 回だけ出す。分割セルと広い画面では出さない（同じ値が並ぶため。2026-11-04 追記）
- 複数スペースのペインが並ぶときだけ、分割セルの見出しにペイン名の右へスペース名（`--text-secondary`）を添える。1 スペースだけなら出さない（2026-11-11 追記、[ADR 0058](0058-split-view-tab-history.md)）
  - 別スペースに同名のペイン（`review` や `shell` など）があると、名前だけでは区別できない
  - タブバーの 2 段目と同じ条件・同じ値を使う。スペース名は省略可とし、フルは `title` に置く
  - linked worktree のスペース名は、Herdr が付ける `worktree-` を落として表示する。狭いタブやセルでは前置きに幅を食われ、呼び名が隠れるため。ラベルの無いペインの端末タイトルも同じ名前になるので、タブと分割セルの 1 段目もこの表記に揃える。1 段目がスペース名と同じ表記になるときは、タブの 2 段目とセルのスペース名チップで同じ文字列を繰り返さない。フルは `title` と aria に残す（2026-11-11 追記）
- セルの場所チップでは、リンクされたワークツリーのスペース名の左に作成元のスペース名を `›` で添える（2026-11-20 追記）
  - 分割セルはブランチもリポジトリ名も出さない。ワークツリー名はランダムで、どのリポジトリの作業かを名前から読めない
  - Herdr のサイドバーと同じく、ワークツリーは作成元のスペースの下に並ぶ。左に置くのは `repoName` ではなく、そのスペースのラベル（TUI と同じ名前）。作成元を `workspace.rename` で改名していると、一覧の束の見出し（`repoName`）とは違う文字列になる
  - 作成元のスペースが閉じているとラベルは読めない。リンクされたワークツリーの自動ラベルはリポジトリ名から作られるので `repoName` で代える
  - リポジトリ本体のセルは作成元を持たないので、スペース名だけを出す（`hwc › hwc` にしない）
  - 見出しの名前と同じ文字列になる部分は落とし、残りが無ければチップを出さない。名前の無いペインは見出しが場所そのものなので、チップは出ない
  - タブバーの 2 段目は今までどおりスペース名だけにする。狭いタブでは作成元のぶん呼び名が隠れる
  - 幅が足りないときは作成元から先に縮める。スペース名は 10em、チップ全体は 17em を上限に省略する

## Consequences

- ペインがワークスペースのディレクトリ以外へ `cd` している場合、2 段目は実際のブランチと違うことがある（ワークスペース単位の近似）
- ラベルの無いシェルが同じタブに複数あると、タブと一覧では同じ `シェル` が並ぶ。広い画面の詳細ヘッダか、ペインメニュー先頭のペイン ID で見分ける。別スペースに同名のペインがある場合は、タブの 2 段目とセル見出しのスペース名で区別できる（2026-11-11 追記）
- ブランチの表示は最大 TTL 秒ぶん古いことがある
- セルの場所チップは、ワークツリーのセルで `hwc › silver-cloud-1` の 2 語になる。作成元のスペースを閉じている間はリポジトリ名に変わる（自動ラベルと同じ値なので、通常は同じ文字列）。狭いセルでは作成元が省略され、`… › silver-cloud-1` になる
- PR のチップの有無は場所のチップに影響しない。PR が無い・open でない・まだ引けていないセルでも、場所は snapshot だけで出る
- 端末タイトルは一覧から見えなくなる。タブと分割セルの見出しでは、ラベルの無いペインのときだけ見える。1 枚表示の見出しは、狭い画面ではブランチを出し、広い画面ではブランチを出さず PR のチップだけを出す。分割セルもブランチを出さず、PR のチップだけを出す（[ADR 0043](0043-pane-head-pull-request.md)）
- git 管理外のディレクトリでは 2 段目が無く、行が 1 段になる

## Alternatives

- 行に 3 段目を足す: 高さが増え、狭い画面で一覧が読めなくなる
- シェルを `bash` と呼ぶ: 実際のシェルは Herdr のスナップショットから分からない（zsh / fish などがある）ため、役割を表す `シェル` にした
- 詳細ヘッダにブランチを出す: ブランチはペインではなくワークスペースの属性で、全ペインに同じ文字列が並ぶ
- BFF で `git rev-parse` を叩く: プロセス起動が要る。`.git/HEAD` の読み取りで足りる
- セルの左に `repoName` を出す: 作成元の自動ラベルの元になる値なので、通常は同じ文字列で足りる。ただしスペースを改名していると Herdr の TUI と食い違う。BFF に新しい値を足さず、開いているスペースから作れ。
