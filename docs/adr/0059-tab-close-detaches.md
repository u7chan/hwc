# ADR 0059: タブの × はペインを閉じず、タブから外す

- Status: Accepted
- Date: 2026-11-11
- Revises: [ADR 0021](0021-pane-close.md) のタブの ×、[ADR 0029](0029-preserve-last-pane.md) の × の出し分け、[ADR 0058](0058-split-view-tab-history.md) の「閉じる」
- Revises: 2026-11-11 に空きスロットを廃止し、タブを外したら葉を畳んで組み直す（[ADR 0061](0061-split-view-directional-tree.md)）

## Context

[ADR 0021](0021-pane-close.md) と [ADR 0058](0058-split-view-tab-history.md) は、タブの × を「そのペインを閉じる（スペース最後のエージェントなら終了する）」入口にした。確認ダイアログを挟み、`paneCloseAction` で close と exit を出し分けていた。

タブは開いたペインの履歴で、× はブラウザのタブと同じく「この画面から外す」と読む。閉じるつもりのない利用者が × を押すと、確認はあるもののエージェントが止まり、開いていた作業が失われる。タブを片付ける目的と、エージェントを終える目的は別で、同じ入口に置くと取り違える。

## Decision

- タブの × と中クリックは `openTabs` から外すだけにする。BFF へ要求せず、確認も挟まない。ペインは Herdr 側で動き続け、一覧から開き直せる
- 外したタブが `slots` にあれば、その位置は空きにする。自動で詰めない（[ADR 0058](0058-split-view-tab-history.md) の空きスロットの規則）。current を外したときだけ、開いた順の次（無ければ手前）を選ぶ
- × は全てのタブに出す。`paneCloseAction` による出し分けと「最後のペインのため閉じられません」の説明は無くす。aria と title は「タブから外す」
- ペインを閉じる / エージェントを終了は、ペイン見出しと一覧の行の三点リーダーメニューだけに残す。確認・`paneCloseAction`・[ADR 0029](0029-preserve-last-pane.md) の規則は変えない
- タブから外したペインのプレビューは、対象ペインを開いている間だけ出す既存の規則でタブから消える
- close の成功後に行う後始末は、同じ「タブから外す」遷移を使う
- 外すタブは幅を詰めながら淡く消し、そのペインがセルや本文に出ていれば同じ時間だけ本文も淡く消す。`prefers-reduced-motion` では即時に外す。スナップショットの適用はアニメーションの完了まで遅らせるが、遅らせるのは描画だけで、状態の正は BFF のまま（[ADR 0034](0034-remove-worktree.md) と同じ）

## Consequences

- タブを片付けてもエージェントは止まらない。誤って × を押しても作業は失われない
- タブから外したペインを戻すには一覧から開く。開き直すと履歴の右端に積まれる（[ADR 0058](0058-split-view-tab-history.md)）
- グリッドのスロットは空いたまま残る。閉じた位置を保ち、空きスロットの × で詰める
- 最後のシェルもタブから外せる。Herdr 側のペインとスペースは残る
- エージェントを終えるには、タブを選んでペイン見出しの三点リーダーメニューを開くか、一覧の行メニューを使う
- タブの × では確認が出ない。取り消せない操作ではなくなったため
- タブを外す反映は 180ms 遅れる。連続で外したときは前の対象をすぐ反映し、アニメーションは後の対象だけに出す。閉じる要求の応答より先にペインが消えたスナップショットが届いた場合も、消えるタブを見せてから一覧を更新する

## Alternatives

- **× に確認を残して close する**: タブを片付ける目的とエージェントを止める目的が混ざる。今回の取り違えの原因
- **× を「タブから外す」と「閉じる」のメニューにする**: タブの × にメニューを挟むと、ブラウザのタブと同じ即時の操作にならない
- **タブに三点リーダーを足す**: 閉じる入口がタブ内に増え、× との違いがまた曖昧になる。ペイン見出しと一覧の行のメニューで足りる
- **外したタブを undo できるようにする**: ペインは生きているので、一覧から開き直せば足りる
