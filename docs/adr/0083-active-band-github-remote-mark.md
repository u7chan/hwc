# ADR 0083: アクティブ帯のリポジトリ名に GitHub リモートの印を添える

- Status: Accepted
- Date: 2026-11-14

## Context

[ADR 0017](0017-active-agents-view.md) のアクティブ帯は、2 段目にリポジトリ名とブランチを出す。だが、そのリポジトリにリモートがあるのか、ローカルの git だけなのか、git 管理外なのかを一覧から読み取れない。同じリポジトリ名の帯が並んでいても、手元だけで作業しているのか、GitHub に push 済みなのかが分からない。

先頭のアイコンは「非 git / リポジトリ / linked worktree」の種類を表す（[ADR 0072](0072-github-remote-link.md) / [ADR 0075](0075-git-kind-from-checkout.md)）。この意味は変えられない。一方、リモートの有無は [ADR 0072](0072-github-remote-link.md) が足した `GitSync.repoUrl` から読める。GitHub の記号はスペースメニューと PC のチャット見出しでも既に使っている。

## Decision

- アクティブ帯のリポジトリ名の左に、`workspace.sync.repoUrl` が非 null のときだけ GitHub の記号（`GitHubIcon`）を置く
- 記号は読む面であって入口ではない。リンクにもメニューにもしない。GitHub のリポジトリを開く入口は、スペースメニューと PC のチャット見出しのまま（[ADR 0072](0072-github-remote-link.md)）
- 記号は `--color-secondary`、リポジトリ名とは `--space-1` 空ける。リポジトリ名が省略されても記号は残す
- 読み上げには `GitHub リモートあり` を添える。色だけで意味を持たせない
- 記号を出す条件はリポジトリ名を出す条件の中に置く。git 管理外のスペースはリポジトリ名を持たないため、記号も出ない
- 帯の 1 段目・2 段目の構成、および「すべて」ツリー・詳細・メニューの表示は変えない

## Consequences

- GitHub のリモートがある帯は、リポジトリ名の左の記号で分かる。ローカルのみのリポジトリは名前だけ、git 管理外は名前も記号も出ない。先頭のアイコンと合わせて 3 種類を見分けられる
- GitHub 以外のリモート（GitLab など）は、ローカルのみのリポジトリと同じ見た目になる。`repoUrl` は GitHub の URL だけを正規化するため（[ADR 0072](0072-github-remote-link.md)）
- `sync` を読めていないとき（git の失敗、detached HEAD など）も記号は出ない。ブランチ行自体が出ない場合は、リポジトリ名ごと出ない
- 記号のぶん狭い幅でリポジトリ名が早く省略される。記号は残るので、リモートの有無は読み取れる
- 記号は押せない。GitHub を開くにはスペースメニューを使う
- リモートの有無は 10 秒キャッシュの `sync` に従う。リモートを足した直後は最大 10 秒古い

## Alternatives

- **先頭アイコンを GitHub アイコンに置き換える**: [ADR 0072](0072-github-remote-link.md) で却下済み。非 git / リポジトリ / linked worktree の区別が消える
- **`hasRemote` で記号を出す**: GitHub 以外のリモートにも GitHub アイコンが付き、GitHub の URL が無いのに GitHub だと誤解させる
- **GitHub アイコンをリンクにする**: 帯の読み面に小さなリンクが増え、モバイルで誤タップしやすい。スペースの操作はスペースメニューに 1 つという原則（[ADR 0034](0034-remove-worktree.md)）からも外れる
- **ローカルのみのリポジトリに別の記号を出す**: 先頭アイコンが既に種類を表しており、名前の横に 2 つ目の git 記号を置くと意味が重なる。名前の有無と先頭アイコンで足りる
- **GitHub 以外のリモートにも汎用の記号を出す**: 今の hwc に GitHub 以外を扱う機能は無く、記号の意味を増やすだけになる
- **「すべて」ツリーにも同じ記号を出す**: 今回の目的はアクティブ一覧での判別で、ツリーは見出しが PR タイトルになる。同じ記号を置く場所と幅は別に検討する

## Verification

- 架空 Herdr と架空 git の E2E で、GitHub リモートのある帯に記号が出ること、`hasRemote: false` のリポジトリと git 管理外の帯に記号が出ないことを確認する
- 目視で 320 / 390 / 1280px、ライト / ダーク、長いリポジトリ名を確認する
