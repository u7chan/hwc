# ADR 0115: 一覧では単一タブの行を出さない

- Status: Accepted
- Date: 2026-11-21

## Context

`すべて` のツリーはワークスペース → タブ → ペインの 3 段で、タブ行は複数のタブを束ねる見出しとして置いていた。hwc にはタブを作る入口が無く、タブは Herdr TUI でしか作れない。そのため、ほとんどのワークスペースは既定名のタブを 1 つだけ持つ。

スペース自身の見出しがある場所では、タブが 1 つならタブ行を省き、ペインを直下に並べていた。省いていたのは、タブ行が「見出しを持たないスペース（リポジトリ束ねの host）で開閉を持つ唯一の行」になる場合を除くためである。結果として、リポジトリ束ねの host だけが `1` という既定名のタブ行を出していた。ペインを束ねていない段が 1 つ増え、同じツリーの中でも場所によって段の深さが変わっていた。

アクティブ一覧では、タブが 1 つのときタブ名を出さない（[ADR 0017](0017-active-agents-view.md)）。ツリーだけが既定名を残していた。

## Decision

- `すべて` のツリーでも、タブが 1 つだけならタブ行を省く。スペース自身の見出しの有無で分けない
- タブ行は 2 つ以上のタブを束ねるときだけ出す。Herdr TUI でタブを増やした場合の束ねは残す
- リポジトリ束ねの host は、束の見出しの開閉に従ってペインを直下に並べる。host のペインだけを個別に畳む操作は持たない

## Consequences

- host のペインは、リンクされたワークツリーの見出しと同じ深さに並ぶ。ペインと見出しは行の記号・状態・副題で区別する
- `すべて` のツリーは、タブが 1 つの間はワークスペース → ペインの 2 段になる。タブが 2 つ以上ある場所だけ 3 段になる
- タブ名（既定名の `1` を含む）は、2 つ以上のタブを束ねるときだけ見える
- リポジトリ束ねの host に複数のタブがあれば、タブ行はこれまでどおり出る。束の見出しは host の入口と開閉を兼ねたまま

## Alternatives

- **タブ段を完全になくす**: Hwc でタブを作れない以上、ペインをワークスペース直下に並べるだけでも足りる。ただし Herdr TUI で複数タブを使っている場合に束ねが失われ、別のタブのペインが同じ並びに混ざる。アクティブ一覧が複数タブのときだけタブ名を出す規則とも食い違う
- **タブ行を残し、既定名の `1` をブランチ名などに置き換える**: 段は減らず、タブの見出しにタブ以外の値を出すことになる
- **host のペインだけを畳む行を残す**: 今回減らしたい段そのもので、開閉のためだけに見出しを 1 段足すことになる
