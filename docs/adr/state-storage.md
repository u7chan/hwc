# hwc が持つ状態は、共有の設定を状態ディレクトリ、端末ごとの好みを localStorage に置く

- Status: Accepted

## Context

hwc 自身が覚える必要のあるものは少ない。ワークスペース・タブ・ペインの構造と名前は Herdr、会話は各エージェントのセッションが正で、hwc は複製を持たない（[Herdr 連携](herdr-socket.md)）。

それでも、添付ファイル、通知や再起動コマンドの設定、エージェントの起動の既定、Claude に渡す hook と mod の出力などは hwc が書き出す。作業ツリーに置くとリポジトリを汚し、ペインを作り直すと場所が変わる。

一方、テーマ・分割の動き・ツリーの位置・ライブ更新の間隔などは、端末ごとの見え方と電池の好みで、PC とスマホで変えたいことがある。

## Decision

- hwc が書き出すものはすべて状態ディレクトリ `$HWC_STATE_DIR`（既定は `${XDG_STATE_HOME:-~/.local/state}/hwc`）の下に置く。絶対パスでない値は採らず、既定へ落とす。根の解決は `defaultStateRoot` に共通化する
- 内容を丸ごと置き換えるファイル（ペイン時刻、通知・再起動・定型文・起動の既定の設定、Claude の応答待ちの sidecar）は、同じディレクトリの tmp に書いてから rename で置き換える。利用者が画面から保存する設定は、並行した書き込みや前回の残骸とぶつからないよう一意な tmp 名を使う。読めない・壊れた値は項目ごとに既定へ落とし、起動を止めない
- 資格情報を含むファイル（Discord の Webhook URL）と、Claude 連携のファイル（`--settings` で渡す設定、承認待ちのコマンドやパスを含む応答待ちの sidecar）は 0600 で書く
- 全端末で共有する設定は BFF が状態ディレクトリに持つ。端末ごとの見え方の好みは client の `localStorage` に置き、BFF には送らない
- 例外は pi の `ask_user` への回答 `<session path>.ask.answer.json` だけ。pi 拡張への一時的な受け渡しで、パスはセッション path からしか導けず、hwc が保持する状態ではない。BFF がペイン id から path を導き、クライアントからは受け取らない。この 1 ファイル以外に例外を広げない。pending（`<session path>.ask.json`）は mypi が書くので、この ADR の対象外（[pi 連携](pi-integration.md)）
- SQLite などの二次ストアは持たない。会話とペインの状態はその都度、正の持ち主から読む

## Consequences

- マシンを作り直したら設定は入れ直す（[docs/deploy.md](../deploy.md)）
- 添付ファイルは自動では消えない（[添付](attachments.md)）
- 端末の好みはブラウザごとに別で、同期しない
- pi の answer は状態ディレクトリのバックアップには含まれない。pi が読むか、mypi が次の質問の開始前に消すまでの短命なファイルで、hwc が復元するものではない

## Alternatives

- **ペインの cwd 配下に置く**: エージェントが相対パスで開けるが、作業ツリーを汚し、ペインの作り直しでパスが変わる
- **好みも BFF に保存する**: 端末をまたいで揃うが、PC とスマホで変えたい好みまで揃ってしまう
