# ADR 0108: Claude のモデルは表示名で出し、起動時の指定と実際のモデルを区別する

- Status: Accepted
- Date: 2026-11-20
- Amended by: [ADR 0114](0114-model-label-by-agent.md)（作成ダイアログの選択肢も Claude は表示名にし、Codex / OpenCode は provider を落とす）
- Amends: [ADR 0101](0101-launch-model-while-chat-unavailable.md) の「出す値は起動時に選んだモデル id（Claude では `sonnet` などのエイリアス）と effort にする」。[ADR 0096](0096-claude-model-effort.md) の Consequences の「ダイアログの表示は `claude/opus` のようになり、`Opus 5.5` のような版付きの名前は出ない」

## Context

Claude のモデルは、最初のメッセージの前は起動時に選んだエイリアス（`opus`）、応答が記録された後は transcript のモデル id（`claude-opus-5-5`）が、そのまま入力欄に出る。TUI の status line は `Opus 5.5` と出すので、hwc の表記だけが公式の名前から離れている。最初のメッセージを送ると `opus` から `claude-opus-5-5` へ表記の体系ごと変わり、狭いスマホの画面ではチップにも収まりにくい。

2 つの値は確からしさも違う。エイリアスは起動時に頼んだ値で、実際に動いているモデルとは限らない（最初のメッセージ前に TUI で切り替えても変わらない。[ADR 0033](0033-launch-model-before-first-message.md)）。transcript のモデル id は実際に応答したモデルである。どちらも同じ「モデル名」に見えて、この差が伝わらない。

## Decision

- 表示名は `claude-<family>-<major>-<minor>[-<yyyymmdd>]` の id から導出する（`claude-opus-5-5` は `Opus 5.5`）。エイリアスは family 名だけにする（`opus` は `Opus`）。解決先の版は起動するまで分からないので、推測しない。読めない id（旧形式、日付だけの id、他プロバイダーの id）は、そのまま出す
- 入力欄のモデルのチップは、Claude のペインだけ表示名にする。他のエージェントは変えない
- チップを開くパネルは識別子（エイリアスまたはモデル id）を出し、コピーの対象も識別子にする
- 値がエイリアスのとき（起動時の指定で、実際のモデルは未確定）は、パネルのモデル行に `ⓘ` を付け、「起動時の指定。最初の応答で実際のモデルに確定します」と注記する。チップには付けない（版の有無で暫定か確定かが分かる）。暫定かどうかは値から描画中に導き、状態は持たない
- 作成ダイアログのモデルの選択肢と、設定画面のモデルの行は、Claude に限りエイリアスの表示名（`Opus`）にする。候補と起動引数は変えない
- `CLAUDE_MODEL_ALIASES` は、候補（BFF）と表示（クライアント）が同じものを見るよう `shared` に置く

## Consequences

- 最初のメッセージの前後で、`Opus` から `Opus 5.5` へ版が加わるだけになる。表記の体系は変わらない
- 表示名を出すために、status line の読み取りも、CLI のモデルカタログも、版付きの対応表も要らない。版が上がっても hwc の更新は要らない
- 導出は id の形に依存する。Anthropic が id の形を変えたら、表示は生の id に戻る（誤った名前は出さない）。`[1m]` のような接尾辞付きの id も、いまは生の id のまま出る
- TUI の表示名と一致しない場合がある（コンテキスト窓などの付記は出さない）
- Pi 経由で使う Claude のモデル（`claude-sonnet-4-5`）は、`provider/id` が選択の一部なので変えない

## Alternatives

- **TUI の status line の表示名を読む**: 公式の名前を出せるが、折り返しと再描画に依存し、版で字が変わる（[ADR 0101](0101-launch-model-while-chat-unavailable.md)）
- **CLI のモデルカタログのキャッシュを読む**: 表示名が得られるが、公開形式ではなく、有無・鮮度・形式変更に依存する（[ADR 0096](0096-claude-model-effort.md)）
- **版付きの対応表を hwc に持つ**: リリースごとに更新が要る
- **エイリアスの暫定を `!` の記号で示す**: 警告やエラーと読まれる。不具合ではなく暫定なので `ⓘ` にする
- **`ⓘ` を押すと注記が開く形にする**: スマホではホバーが無く、開く操作が 1 つ増える。パネルはすでに開いているので、注記は最初から出す
