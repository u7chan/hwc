# ADR 0027: 新しいペインは名前と起動エージェントをダイアログで選ぶ

- Status: Accepted
- Date: 2026-11-04

## Context

ADR 0026 で詳細の見出しからシェルペインを 1 枚作れるようにした。次に、ペイン名を付け、Pi / Claude / Codex / OpenCode のどれかを起動してから作りたい。

Herdr の `agent.start` は既存のシェルペインに `{ pane_id, kind, name, timeout_ms }` を渡し、TUI の準備完了まで待つ。エージェント名は小文字英数字・`-`・`_` の 1〜32 文字に限られ、日本語や空白は使えない。`pane.rename` はペインのラベルを変える。エージェントの起動は通常のソケット期限（8 秒）より長くかかることがあり、Claude は初回にフォルダを信用するか尋ねる。Codex はこの環境では CLI が起動できない。Claude / OpenCode は hwc のチャットや状態表示にはまだ対応していない。

設定のテーマピッカーは、狭い画面で長い名前を選ぶと、太字による折り返しの変化と、外側に描くフォーカスリングで枠が膨らんで見えた。同じカード部品をエージェント選択に使うため、ここも直す。

## Decision

- 詳細の「…」メニューの「新しいペイン」は即時作成ではなく、ダイアログを開く入口にする
- ダイアログはペイン名（任意、80 文字まで、前後の空白は落とす）と、次の 2 タブを持つ
  - 「エージェント」: Pi → Claude → Codex → OpenCode の 2 列カード。既定は Pi。カードは Provider アイコン + ラベルで、テーマピッカーと同じ部品を使う
  - 「シェル」: エージェントを起動せず、名前だけ付けたシェルペインを作る
- API は `POST /api/panes/:id/split` の body に `{ name?: string | null, agent?: kind | null }` を取る。モデル指定による拡張と、そのときの起動引数・期限は [ADR 0030](0030-new-pane-model.md) に従う。分割位置と 4 枚上限は ADR 0026 のまま
- 作成は 分割 → `agent.start` → `pane.rename` の順。エージェント名は Herdr の制約に合わせて `hwc-<paneId>` を自動で付ける（例: `hwc-w1-p4`）。ユーザーのペイン名は label にだけ使い、日本語や空白も許す。cwd は指定せず Herdr の `terminal.new_cwd` に任せ、`pane.split` の focus は既定の false のまま
- `agent.start` は `timeout_ms` 30 秒、ソケットは 35 秒、クライアントは 65 秒で切る。分割直後は Herdr が `agent_pane_busy` を返すので、シェルが準備できるまで最大 5 秒・150ms 間隔でリトライする。クライアントの期限切れは、ペインができているか確認できないため、ダイアログを「閉じる」にして再送させない。期限切れの判定は reject の名前ではなく AbortSignal の aborted を使う（WebKit は中断された fetch を AbortError で返すため）。送信中はスピナーと「起動中…」/「作成中…」を出し、ダイアログを閉じられず二重送信もできない
- エージェント起動に失敗したら、分割済みのペインはシェルとして残す。API は `502 { error, paneId }` の部分成功を返し、ダイアログにエラーと「閉じる」を出す。分割自体の失敗はペインが無いので、ダイアログにエラーを出して再試行できる
- リネームだけ失敗した場合もペインは残し、`502 { error: "pane_rename_failed", paneId }` で知らせる
- Codex の CLI 有無は検出しない。選択されたら起動を試み、失敗は上の部分成功として扱う。Claude の trust prompt は操作せず、起動できたかだけを見る
- `agent.start` が `agent_not_ready` を返しても、エージェント自体は起動している（Claude の trust prompt、OpenCode の初回画面など）。この場合は失敗にせず、ペインを名前付きで残して成功として開く。hwc からプロンプトは操作しない
- テーマカードは `ChoiceCard` として共通化する。選択中も太字にせず、枠色と面で示す。フォーカスリングはカードの内側に描き、選択で高さが変わらないようにする。長い名前は 2 行のまま許容する

## Consequences

- 名前を空にすると、ペインのラベルは付けない。ツリーの表示は label → title → agent → id の順に落ちる
- エージェントの起動に失敗しても空のシェルは残る。ユーザーはそのまま使うか、閉じるか、別のペインを作り直せる
- Claude は起動できても、hwc のチャット・状態表示・コマンドは Pi と同じようには使えない。起動確認だけをこの変更の完了条件にする。OpenCode は起動に加えて会話の表示にも対応した（[ADR 0028](0028-opencode-chat.md)）
- 起動待ちは最大 30 秒。スピナーは出るが、スマホでは長く感じる可能性がある
- タイムアウト後に Herdr 側でプロセスが動き続ける可能性がある。閉じると動いているエージェントを殺すため、ペインは残す
- シェルの準備待ちが 5 秒を超えると `agent_pane_busy` のまま失敗する。分割自体は成功しているので、ペインはシェルとして残る
- テーマピッカーの長い名前は 2 行のままなので、行の高さは名前の長さで変わる。選択による高さの変化はなくなる
