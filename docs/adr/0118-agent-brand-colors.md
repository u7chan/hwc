# ADR 0118: エージェントのマークは本家の配色で描く

- Status: Accepted
- Date: 2026-11-21
- Amends: [ADR 0116](0116-agent-mark-brand-color.md)（ブランド色を持つのは Claude だけ、という決定）

## Context

ADR 0116 は、マークの色を 1 か所で決める一方、ブランド色を持つのは Claude だけとした。Codex と OpenCode のマークはモノクロが公式で、Pi のマークは 3 色なので、1 色に潰すとブランド色を作ることになる、という理由だった。

実際の画面では Claude だけがオレンジで、Pi・Codex・OpenCode は補助アイコンのグレーになる。本家のマークを使っているのに、本家の見分け（Pi の 3 色、OpenCode の濃淡）は出ていない。ADR 0116 自身も「Pi を単色で色付けしたくなったら、3 色のロゴを 1 色に潰すのではなく、3 色のマークとして描き直すかを先に決める」と、この判断を保留していた。

本家のアセットを確かめると、いずれも色は決まっている。

- Pi: コーラル `#F09082`、青 `#4D9ABF`、黄 `#F1BE58`（[press kit](https://pi.dev/press-kit) の `logo.svg`）
- OpenCode: 輪郭 `#1F1F1F` と、その 20% の内側シェード。暗い地は `#EEEEEE` と 28%（[brand](https://opencode.ai/brand)）
- Codex（OpenAI）: 黒。暗い地では白

「ブランド色を持たない」のではなく、ブランド色がモノクロか複数色だった。

## Decision

- マークは本家の配色で描く。Pi は 3 色、OpenCode は輪郭と内側のシェード、Codex は黒（ダークでは白）、Claude は今までどおり
- 値は `tokens.css` の `--color-agent-*` に置く。Pi・Codex・OpenCode は明暗で変わるものだけ `:root[data-scheme="dark"]` で上書きし、20 テーマぶんは複製しない。Claude は従来どおりテーマごとの `--color-agent-claude` を使う。ブランド色はテーマに合わせて作り直す色ではない
- 形も本家のアセットに合わせる。Pi は 3 パス、OpenCode は 4:5 の輪郭とシェード。マークの枠は変えず、OpenCode は高さに合わせて横を中央に置く
- OpenCode の内側は、不透明な色ではなく `fill-opacity` で地を透かす。行の面・選択した面・控えめな面のどれでも本家と同じ見え方になる
- ライトで 3:1 を割る Pi の黄（1.7:1）は、本家の値をそのまま使う。マークは隣に名前がある装飾で、色だけで意味を持たせない
- 選択中・現在地は面と文字で示し、マークの色では示さない（ADR 0116 のまま）

## Consequences

- 一覧・ペイン見出し・入力欄・作成ダイアログ・設定のすべてで、マークが本家の色になる。面ごとの違いは残らない
- Codex の黒と OpenCode の濃いグレーは、行の名前より濃い記号になる。一覧では目立つが、マークは 18px で名前の手前にあり、行の読み順は変えない
- Pi・Codex・OpenCode の値は明暗 2 系統で足り、テーマを足しても増えない。明暗で変わるのは Codex と OpenCode の濃さだけ
- Pi の黄はライトで薄い。色だけで Pi を見分けるのではなく、形と並びで見分ける前提にする
- ADR 0116 の「ブランド色のあるエージェントを足すときは 20 テーマ分の値と `theme.test.ts` の `PALETTE_TOKENS` が要る」は、明暗 2 系統の `--color-agent-*` に置き換わる

## Alternatives

- **ADR 0116 のまま Claude だけ色を付ける**: 本家の見分けが出ず、同じマークが本家と違う色になる
- **ライトだけ明度を落とす**: 3 色とも 3:1 を超えるが、Pi が茶色寄りになり本家の色に見えない（比較用のカタログで確認した）
- **すべて 1 色に潰す**: 実装は単純だが、Pi の 3 色と OpenCode の濃淡が失われる
- **20 テーマぶん値を複製する**: どのテーマでも同じブランド色なので、複製しても値は変わらない
