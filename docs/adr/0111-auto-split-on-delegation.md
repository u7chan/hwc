# ADR 0111: 委譲で現れたペインを、表示中のセルの隣に自動で分割する

- Status: Accepted
- Date: 2026-11-17
- Revises: [ADR 0061](0061-split-view-directional-tree.md) の「分割の入口はドラッグだけ」

## Context

作業を別ペインのエージェントへ委譲すると、Herdr はペインを増やす。hwc の分割ビューはクライアント側の状態で最大 4 枚まで並べられるが（[ADR 0061](0061-split-view-directional-tree.md)）、増えたペインはタブに加わるだけで、どのペインが何をしているかを目で追うには一覧かタブを開く必要がある。委譲した瞬間に、委譲元の隣で子が動き出すことが分かれば、状態の変化を追いやすい。

Herdr は委譲そのものをイベントにしない。`agent.prompt` はメソッドとして存在するが、呼び出し元や意図は通知されず、`pane.created` の payload も `PaneInfo` だけで、どのペインから分割されたかを含まない。ラッパーや子のセッションに痕跡を残す方法もあるが、経路が限定され、画面の再描画にも左右される。

## Decision

### 検知

- Herdr のスナップショットを前回と比べ、**エージェントが付いたペインが新しく現れた**ときに委譲とみなす。シェルは数えない。`pane.split` の直後はシェルなので、エージェントが検出された時点で反応する
- 新しいペインと同じタブに、いま画面に出ているセルがあるときだけ差し込む。見ていないタブの作業で画面を動かさない
- 最初のスナップショットと、再接続後の最初のスナップショットは差分の基準にしない。切断中に増えたペインを一斉に開かない
- hwc の「新しいペイン」から作ったペインは対象外にする。既存の `pendingSelect` が選択を移すので、二重に動かさない
- PC（`wide`）だけ。狭い画面は 1 枚表示なので、タブのままにする

### 配置

新しいペインは、既存のセルを 1 つ割って差し込む。選択（`current`）は動かさない。

| いまのセル | 差し込む先                          |
| ---------- | ----------------------------------- |
| 1 枚       | そのセルの右                        |
| 2 枚       | 左のセル（委譲元）の下              |
| 3 枚       | 右のセルの下（2x2 になる）          |
| 4 枚       | 差し込まない。`openTabs` にだけ足す |

3 枚目を右に積むと 4 枚目でスロット色が入れ替わり、位置と色の対応が崩れる。左列・右列の順に下へ伸ばすと、各段階が既存セルの分割だけで済み、色も動かない。

手で組んだ木では、上の形にこだわらず差し込める向きを探す。どこにも入らなければタブへ回す。

### 動き

- 新しいセルの `flex-grow` を 0 から 1 へ戻し、既存セルを押し縮める。分割線が走って見える。中身は専用のフェードを足さず、幅の伸びとともに現れる
- 時間は `--hwc-split-duration`
- 端末の `prefers-reduced-motion` は設定より優先して止める

### 設定

設定に「ペイン分割」を足す。どちらも端末ごとの好みなので localStorage に置き、BFF には送らない（[ADR 0058](0058-split-view-tab-history.md) と同じ扱い）。

- 委譲で自動分割: オン / オフ。オフのときはタブにも足さない
- 分割の動き: なし / ゆっくり / 標準 / 速い（0 / 560 / 280 / 160ms）

## Alternatives

- **委譲ラッパーか子のセッションの痕跡で正確に判定する**: ラッパー経由の委譲しか拾えず、TUI の再描画に依存する。表示のためだけに正確さを買う割に合わない
- **読み順から毎回 2x2 を組み直す**: 手で並べた配置を壊す。差し込みで足りる
- **2 枚までに制限する**: 3 枚目以降の委譲がタブに埋もれ、この ADR の目的を満たさない

## Consequences

- 委譲以外の理由で新しく起動したエージェントも分割される。Herdr から理由を区別する材料が無いため、受け入れる
- 再接続中に増えたペインは自動で開かない。必要なら一覧から開く
- 自動分割をオフにしても、ドラッグによる分割とタブの並べ替えは変えない
