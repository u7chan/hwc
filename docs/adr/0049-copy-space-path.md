# ADR 0049: スペースの作業ディレクトリをコピーできるようにする

- Status: Accepted
- Date: 2026-11-09

## Context

別のスペースのディレクトリを、いま見ているエージェントのプロンプトやコマンドへ渡したいことがある。hwc はスペースのパスを画面に出しておらず、一覧の見出しの `title` を頼るしかない。

一覧は同じリポジトリのワークツリーを 1 つの束にまとめる。束の見出しはリポジトリ名で、`title` は `repoRoot` を持つ。リンクされたワークツリーの見出しは `checkoutPath` を持つ。git 管理外のスペースはどちらも持たない。見出しの `title` をそのままコピーすると、束の見出しではリポジトリのルートをコピーし、git 管理外のスペースではコピーできない。

## Decision

- コピーする値は、スペースの作業ディレクトリ 1 本にする。リンクしたいのはリポジトリの親ではなく、そのスペースのペインが作業している場所だから
- BFF の `checkoutPaths` と同じ解決を使い、`WorkspaceState.path` として状態に載せる。worktree の `checkout_path`、先頭ペインの cwd、agent の cwd の順に落とす。解決できなければ `null`
- `workspace.worktree.checkoutPath` はクライアントで使わない。git 管理外のスペースで `null` になり、表示とコピーの対象にならないため
- 一覧のスペースメニューは、先頭にラベルとパス（末尾が見えるように省略）を出し、右端のコピーアイコンで絶対パス全文をコピーする。押してもメニューは閉じない
- ワークツリーの行はそのワークツリーのパス、リポジトリ束ねの見出しは host スペースのパスをコピーする。host の無い束ねにはコピーを出さない。`repoRoot` をコピーする項目は今回作らない
- ペイン詳細の右端メニューには、ペイン ID の下に「スペースのパスをコピー」を 1 項目置く。対象はそのペインのスペースだけにする。全スペースを選ぶピッカーは、一覧のメニューと役割が重なるため作らない
- 表示は `shortenPath` で末尾の区切りから残し、コピーは省略しない。引用符や `~` の短縮は付けない。貼り先がシェルかプロンプトか分からないため
- パスが `null` のときは項目を出さない。コピーの成否は既存のチェックアイコンと `aria-label` だけで伝える

## Consequences

- コピーするのはスペース代表の 1 本で、ペインごとの cwd ではない。同じスペースのペインが別のディレクトリへ `cd` していても、そのペインの cwd はコピーしない
- スマホの詳細画面では一覧が隠れる。別のスペースのパスをコピーするときは一覧へ戻る必要がある。チャット右端のメニューは、いま見ているスペースのパスだけを扱う
- パスに空白や記号が含まれても、そのままコピーする。シェルへ貼るときの引用符は利用者が付ける
- リポジトリのルートをコピーしたい場合は、この機能では満たせない。必要になったら別のラベルで足す

## Alternatives

- **`repoRoot` をコピーする**: リンクされたワークツリーでは親リポジトリを指し、そのスペースの作業場所にならない
- **クライアントだけで `worktree.checkoutPath` を使う**: 状態の変更が要らないが、git 管理外のスペースをコピーできない
- **ペインの cwd を BFF から都度引く**: ペインごとの正確な場所は得られるが、コピーのたびに往復が要り、表示してからコピーするまでの対象も定まらない
- **チャット右端に全スペースのピッカーを出す**: スマホで一覧へ戻らずに済むが、一覧のメニューと同じ選択肢を二重に持つ。まずは一覧のメニューで足りる
- **引用符を付けてコピーする**: シェルへ貼る用途には合うが、プロンプトへ貼ると引用符が本文に入る。用途を決め打ちしない

## Verification

- unit で、`toAppState` が解決済みパスを載せること、worktree のパスと先頭ペインの cwd のフォールバック、`shortenPath` の末尾保持を確認する
- 架空 Herdr の E2E で、リポジトリ本体・リンクされたワークツリー・git 管理外のスペースのメニュー表示と、ペイン詳細のメニューからのコピーを確認する
