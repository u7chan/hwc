# ADR 0014: エージェント本文は移植したパーサで Markdown 描画する

- Status: Accepted
- Date: 2026-11-02

## Context

ペイン詳細の主動線が会話表示になり、エージェントの本文は Markdown を含む。記号をそのまま出していたため、スマホでは読みにくく行数も増える。ADR 0009 は「Markdown 描画のような領域は、自前実装か依存追加かを都度判断する」としている。

`marked` や `markdown-it` は HTML 文字列を返すため、サニタイザも要る。エージェント本文はリポジトリの内容やツール結果を経由して外部由来の文字列を含み得る。一方、u7agent（`u7chan/monorepo` の `projects/u7agent`）には、同じ課題に対して DOM / React 非依存で書かれた自前のパーサとテストがある。hwc で不要なのは生 HTML・LaTeX・Mermaid・シンタックスハイライト・画像解決で、パーサ本体はほぼそのまま使える。

## Decision

- Markdown 専用の外部ライブラリを追加しない（ADR 0009）
- u7agent の `client/src/lib/markdown` を移植元にし、生 HTML・数式・ハイライト・図を削って `src/client/markdown/` に入れる。各ファイルの先頭に移植元を 1 行残す。画像は記法として解析だけし、描くかは BFF が実在を確認したファイルとの照合で決める（[ADR 0055](0055-inline-message-images.md)）
- タスクリストは項目の `task`（true / false）だけを持ち、描画はチェックボックスにする。押した結果は表示だけで、Markdown は書き換えない
- コードフェンスの右上にコピーボタンを置く。hover できる端末では hover で表示し、触れる端末では常に表示する
- HTML 文字列を経由せず、Preact の VNode を組んで描画する。`innerHTML` / `dangerouslySetInnerHTML` / `DOMParser` を使わない（`src/client/markdown/safety.test.ts` が検査する）
- パーサは DOM / Preact / React に依存させない。描画層は `src/client/Markdown.tsx` に置く（ADR 0007）
- 描画するのは agent 本文だけ。user 本文は従来の plain text と折り畳みを維持する
- 200KB（UTF-16 の文字数）を超える本文は解析せずプレーン表示に落とす
- 相対パス・ファイルパスのリンクはリンクにせず、原文の `literal`（等幅）として出す。hwc の BFF はファイルを配信しないため、押しても 404 になる
- 散文は `--font-ui` / `--text-body`、コード・`pre`・`literal` は `--font-mono` / `--text-mono`。見出しはページのアウトラインに混ぜないよう h3〜h6 に写す
- 返信の引用だけを例外とする。user 本文の先頭の blockquote は引用カードとして描画する（[ADR 0022](0022-reply-quote.md)）。本文全体を Markdown にするわけではなく、先頭の連続した `>` 行だけを分解し、残りは従来どおり plain text と折り畳みで出す

### 対応サブセット（契約）

| 記法                                                      | 対応 | 備考                                                                                                                                       |
| --------------------------------------------------------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 見出し `#`〜`######` / 段落 / 段落内改行                  | ✓    | 段落内の改行は `<br>`。見出しは h3〜h6 に写す                                                                                              |
| 強調 `**b**` `*i*` `~~s~~` / コードスパン                 | ✓    | `_` は語中では強調しない（`snake_case` を壊さない）                                                                                        |
| リンク `[t](url "title")` / 自動リンク / 裸の URL         | ✓    | `http` / `https` / `mailto` だけをリンクにする。新しいタブで開く                                                                           |
| 箇条書き / 番号付き / 入れ子                              | ✓    | 番号付きは開始番号を保つ                                                                                                                   |
| 引用 `>` / 水平線                                         | ✓    |                                                                                                                                            |
| 表（パイプテーブル、`:---:` の整列）                      | ✓    | 折り返して読み幅に収め、入らないときは横スクロール。区切り行の列数がヘッダと違うときは表にしない                                           |
| コードフェンス                                            | ✓    | シンタックスハイライトはしない。言語名はラベルとして出し、本文は折り返さず横スクロールする                                                 |
| 生 HTML                                                   | ✗    | タグは文字として出す（`<b>` / `<script>` / `<id>` のいずれも原文）                                                                         |
| 数式 `$…$` `$$…$$` `\(…\)` `\[…\]`                        | ✗    | 区切りごと原文                                                                                                                             |
| 画像 `![]()`                                              | ✓    | BFF が実在を確認したファイルだけを本文の位置に描く。照合できなければ記法ごと原文（`literal`）（[ADR 0055](0055-inline-message-images.md)） |
| タスクリスト `- [ ]`                                      | ✓    | 項目の `task` に完了状態を持つ。押した結果は表示だけで、Markdown は書き換えない                                                            |
| 相対パス・ファイルパスのリンク                            | ✗    | リンクにせず原文（`literal`）を出す                                                                                                        |
| 実体参照 / 脚注 / 参照リンク / HTML ブロック / 遅延継続行 | ✗    | 原文表示                                                                                                                                   |

## Consequences

- CommonMark 完全準拠ではない。参照リンク・脚注・HTML エンティティなどは原文のまま出る
- u7agent と二重管理になる。パーサの修正は手で backport する。差分が大きくなったら共有パッケージ化を再検討する
- パーサのテストが仕様になる（`parse.test.ts` / `inline.test.ts`）。テストは ADR 0007 に従い純関数だけを持つ
- HTML 文字列を作らないため、XSS の面は小さい
- 生 HTML・数式は原文のまま出る。画像記法は、BFF が根の内側で実在を確認したファイルだけ描き、それ以外は原文のまま出る
- タスクリストのチェックは保存しない。開き直すと Markdown の状態に戻る
- 段落の行頭空白は Markdown の慣習に従って落ちる。インデントで揃えた本文は崩れる
- 相対パスやファイルパスのリンクは押せず、原文のまま出る
- 散文はサンセリフ、コードは等幅になる。従来の見た目からの差分が大きい
- 200KB の判定は描画側の解析前に行う。上限を超える本文は Markdown にならない
- 表はモバイルで横スクロールになる。列の多い表は読みにくいまま
- 長いメッセージが多数並ぶペインでは初回描画が重くなる可能性がある。実機で測り、必要ならメッセージ単位のキャッシュを足す
