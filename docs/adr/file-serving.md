# ファイルは根の配下だけを配り、HTML は不透明なオリジンの sandbox で開く

- Status: Accepted

## Context

エージェントは画像・HTML のモック・レポートをファイルに書き、本文にパスを残す。スマホからそれを見たい。ペインのチェックアウトのファイルも、ツリーから開いて読みたい。

認証の無い LAN 公開（[LAN 公開](lan-access.md)）なので、配信は LAN の誰でも読める。HTML を同じオリジンで開くと、その script が BFF の API（`/api/state` の取得や `/api/panes/:id/input` への送信）を叩ける。

## Decision

### 根と解決

- 配信の根は、ワークスペースのチェックアウト、`/tmp`、`HWC_PREVIEW_ROOTS`（`:` 区切りの絶対パス）の順。根の番号は 0 から順に振り、チェックアウトを持たないペインでは `/tmp` が 0 番になる。`/tmp` は literal で、`TMPDIR` も `os.tmpdir()` も見ない（エージェントが本文に書くのは `/tmp/...` だから）
- パスは `realpath` で解決し、実体が根の配下にあるときだけ配る。根の外を指す symlink は配らない
- client へ渡すのは根の番号と根からの相対パスだけ。絶対パスは渡さない。相対名だけで指すと、別の根にある同名ファイルを引くことがあるため、番号を契約に含める
- 本文から拾うのは、BFF が実在を確かめたパスだけ。生成ファイルの台帳は持たない
- 根からの相対パスに `.git` セグメントを含むものと、`.env` とその派生（`.env.` で始まる名前）は配らない
- 配る形式は 1 か所の allowlist に限り、`X-Content-Type-Options: nosniff` を付ける。テキストとして配る経路では先頭に NUL が無いことを確かめ、バイナリは断る
- ファイルツリーはチェックアウトだけを根にし、1 ディレクトリずつ遅延で読む。全体を歩く API は作らない

### HTML の分離

- HTML は `/api/panes/:id/preview/<根の番号>/<相対パス>` のパス形式で配り、モックの相対参照（`./app.css` など）をそのまま解決させる
- iframe は `sandbox="allow-scripts"` だけにする。`allow-same-origin` は付けない。付けるとモックが親の document から自分の sandbox を外せる
- 応答にも `content-security-policy: sandbox allow-scripts` を付け、新しいタブで直接開いたときも不透明なオリジンにする
- 不透明なオリジンから ES modules と `fetch` が動くよう、このルートにだけ `access-control-allow-origin: *` を付ける。他の API は今までどおり読めない
- `allow-top-navigation` / `allow-popups` / `allow-forms` は付けない

## Consequences

- 根の中のファイルは、パスを知っていれば LAN の誰でも読める。一覧は取れず、形式は allowlist に限られる
- `/tmp` は共用なので、モックの相対参照で他のプロジェクトの一時ファイルも読める。`/tmp` は再起動で消える
- プレビューの中では `localStorage` や Cookie が使えない。デザインモックには要らない
- 根の外に書いたファイルはプレビューできない。案内は出すが、動かすのはエージェントか利用者の仕事

## Alternatives

- **別ポート・別オリジンで配信する**: sandbox が要らないが、WSL2 のポート転送をもう 1 本増やす
- **HTML を取得して blob URL で iframe に入れる**: 相対参照が解決できず、直接開いたときの隔離も効かない
- **本文をサニタイズして hwc の DOM に埋め込む**: script を落とすとモックが動かない
- **生成したファイルの台帳を持つ**: エージェントに登録させる必要があり、登録漏れで出ない理由が画面から分からなくなる
- **検出した HTML のディレクトリだけを動的な根にする**: 露出は最小になるが、根の番号が設定から決まらなくなり、`../font.woff2` のような親の参照も壊れる
