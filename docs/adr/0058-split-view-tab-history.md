# ADR 0058: 分割ビューは開いたペインの履歴と 4 スロットのグリッドで持つ

- Status: Accepted
- Date: 2026-11-11
- Supersedes: [ADR 0020](0020-pinned-pane-board.md)
- Revises: [ADR 0021](0021-pane-close.md) の後継の決め方、[ADR 0019](0019-pane-row-content.md) のセル見出し、[ADR 0043](0043-pane-head-pull-request.md) のセルごとの PR
- Revises: 2026-11-11 にタブの × を「タブから外す」に変更（[ADR 0059](0059-tab-close-detaches.md)）
- Revises: 2026-11-11 に 1 枚表示のセル枠を廃止（実ペインが 2 枚以上のときだけ枠を出す）

## Context

PC の分割表示は、選択中ペインが属するタブの兄弟ペインだけを並べていた（`splitPanes`）。表示対象は「選択中タブ − 非表示」で導出し、`hwc-split` / `hwc-hidden-panes` を localStorage に持っていた。分割トグルと Eye（非表示）で出し入れし、4 枚を超えるとタブ内で見えないペインを Eye で隠す運用になる。

並行でワークツリーを回すと、見たいペインは同じタブに揃わない。別スペース（ワークツリー）のペインを同時に見られないため、作業の現在地が 1 枚に閉じる。タブバーもタブ内の切り替えで、開いたペインの履歴ではない。ADR 0020（Proposed）はスペースを跨ぐボードを提案していたが、ピン留めの操作と一覧選択の意味が未決のまま実装されていない。

4 色でスロット位置を示す案は、タブ・セル・一覧の対応を目で追えるようにする。タブから外す入口は、ペインを片付けるたびに詳細へ移る必要を無くす。

## Decision

### 状態

HWC ローカルの 3 つだけを持つ。どれも Herdr の状態ではない。

- `openTabs`: 開いたペイン ID の順序付き配列。全スペースを跨ぎ、一意で、スナップショットに実在するペインだけ
- `current`: タブバーの選択。既存の `selectedPaneId` と同じ値。消えたペインの ID を保持することがある（[ADR 0021](0021-pane-close.md)）
- `slots`: 長さ 0〜4 の配列（ペイン ID または空き）。一意で `openTabs` の部分集合。**レイアウトは slots の長さで決まる**（2 = 1x2、3 = 1+2、4 = 2x2）
- `currentSlot` は持たない。`current` が `slots` にあればその index、無ければ最初の空き、無ければ 0
- 不変条件:
  - `openTabs` は一意・実在のみ
  - `slots` は一意・`openTabs` の部分集合・長さ 4 以下
  - `current` が実在するなら `slots` に 1 回だけ現れる
  - `current` が消えている / null なら `slots` に現れない（そのスロットは空き）

遷移は `src/client/split-view.ts` の純関数が持つ。

| 出来事                                  | `openTabs`       | `slots`                                                                                                               | `current`                                                                     |
| --------------------------------------- | ---------------- | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 一覧 / タブでペインを開く               | 無ければ右端追加 | 既にスロット内ならそのまま。無ければ current スロットを置換。current が null / 消えていれば空き先頭、空きも無ければ 0 | そのペイン                                                                    |
| タブから外す（current）                 | 削除             | そのペインのスロットを空きに                                                                                          | 後継。グリッド内ならそのスロット、グリッド外なら外したスロット、無ければ null |
| タブから外す（current 以外）            | 削除             | そのペインのスロットを空きに                                                                                          | 変えない                                                                      |
| ペインがスナップショットから消える      | 削除             | そのペインのスロットを空きに                                                                                          | ID を保持（表示は一覧）                                                       |
| 消えた current が再出現                 | 右端に追加       | 空き先頭（無ければ 0）へ                                                                                              | そのペイン                                                                    |
| ドラッグ: スロット S の P → 空き T      | 変えない         | P を T へ移し、S を空きに                                                                                             | P が current なら P。それ以外で T が current スロットなら P                   |
| ドラッグ: スロット S の P → 埋まり T(Q) | 変えない         | P と Q を入れ替える                                                                                                   | 同上                                                                          |
| ドラッグ: スロット外の P → 空き T       | 変えない         | P を T に入れる                                                                                                       | T が current スロットなら P。それ以外は変えない                               |
| ドラッグ: スロット外の P → 埋まり T(Q)  | 変えない         | T を P に置換（Q はグリッド外。タブには残る）                                                                         | 同上                                                                          |
| ドラッグ: スロット外の P → 追加帯       | 変えない         | 末尾に追加（4 未満のときだけ）                                                                                        | 変えない                                                                      |
| 空きスロットを閉じる                    | 変えない         | その要素を削除して詰める                                                                                              | 変えない                                                                      |

### タブと 4 スロット

- タブは開いた順の履歴。閉じて開き直したら右端に積む。すでに開いているペインを開いたら選択だけ移す。スペースごとのまとめはしない
- ラベルはペイン名。シェルは前景コマンド名（`paneTabName`）を維持する
- 複数スペースのペインが開いているときだけ 2 段にし、2 段目にスペース名を出す。1 スペースだけなら 2 段目を出さない。1 段目がスペース名と同じ表記になるときは、同じ文字列を 2 段目に繰り返さない（[ADR 0019](0019-pane-row-content.md)、2026-11-11 追記）。2 段目は `--text-secondary`（13px）で、`line-height: var(--line-tight)` の 2 行（17px × 1.2 + 13px × 1.2 + 2px = 38px）をタブの 44px に収める。文字を小さくして詰めない
- タブの `title` と aria にはスペース・タブ・ペイン ID・状態を含める。同一スペース内の同名ペイン（別タブの `shell` など）と、別スペースの同名ペインを区別する
- モバイルも同じ履歴を使い、2 段目も出す。選ぶ前に区別できないと、タップして初めて分かるため
- グリッド外のタブを選ぶと current スロットを置き換える（`slots` が空なら追加）。元のペインはグリッドから外れるが、タブには残る
- 分割の対象は同一スペースに限らず、別スペースのペインも含む。BFF の変更は要らない（詳細のデータはペイン ID 単位、スナップショットは全スペースを持つ）
- セルの `PaneContext` は描画中に `findPaneContext(state, paneId)` で引く。1 つの context を全セルで共有しない（別スペースの PR・ワークツリーメニューが混ざる）
- シェルの前景プロセスは、スロットに入っているペインと current だけ読む。`openTabs` 全部を読むと 3 秒ごとの要求が増える
- `compact`（入力欄を 1 行に畳むか）はセル数ではなく、グリッドに入っているペイン数で判定する
- `current` が null でも、PC では `openTabs` があればタブバーを出し、下に一覧の空状態を出す。グリッドと追加帯は出さない。モバイルは一覧画面に戻る

### タブから外す

- 入口はタブ右端の ×（PC は hover / focus のときだけ、モバイルは常時）、タブの中クリック（PC のみ）、モバイルの × タップ。ペインは閉じず、確認も挟まない（[ADR 0059](0059-tab-close-detaches.md)）
- × は `.hwc-tab-item` の中でタブボタンと兄弟に置く（ボタンの入れ子にしない）。× を押しても中クリックでも選択は変えない
- 全てのタブに × を出し、aria と title は「タブから外す」にする。`paneCloseAction` による出し分けは無い
- 後継は開いた順の次、無ければ手前。選択を動かすのは current を外したときだけ
- 外したペインのスロットは空きとして残す。空きスロットは × で詰める
- ペインを閉じる / エージェントを終了は、ペイン見出しと一覧の行の三点リーダーメニューだけに残す（[ADR 0021](0021-pane-close.md)、[ADR 0029](0029-preserve-last-pane.md)）
- ペインがスナップショットから消えた場合は選択を動かさない（[ADR 0021](0021-pane-close.md)）。そのペインのスロットは空きになる

### 空きスロットと追加帯

- グリッドのタブを外したあと、スロットは空けたまま残す。空きスロットはスロット色の薄い破線枠で、中央に文言は置かない
- 右上の × で空きスロットを閉じる。確認なし（ペインの close ではない）。`slots` から取り除いて詰める
- タブの色は移動先のスロット色に追従する
- current が実在し、`slots.length < 4` のとき、詳細の右端に幅 40px 程度の追加帯を出す。1 枚のときも出す。追加帯はスロットではない（× も 4 色も無い、破線の neutral）
- まだスロットに入っていないペインを追加帯へドロップすると、末尾にスロットを 1 つ足す。スロット内のペインは受け付けない。追加帯は PC だけで、プレビュー表示中は出さない
- 分割トグルは持たない。1 枚目から 2 枚目を作る経路も追加帯に統一する
- current が実在しないとき（空きだけ / 0 を含む）はグリッドと追加帯を畳み、空状態に戻す。スロットは保持する

### ドラッグ

- 起点はタブバー（`openTabs` のペイン）か、グリッドのセル見出し。開始判定は pointer の移動量で行う。タブバー内の並べ替えは持たない（開いた順は変えない）
- 一覧の並べ替え（`order-drag.ts`）は流用しない。対象が DOM の並びではなく `slots` の要素で、落とし先もセルと追加帯で異なる
- 波線ガイドはドロップ先のセル枠（追加帯なら追加帯）に出す
- PC のみ。キーボードだけでのスロット追加は持たない

### 4 色

- 落ち着いた 4 色相（青 / 紫 / 青緑 / ピンク系）をスロット位置に固定する。`src/client/styles/tokens.css` に `--color-slot-1..4` を置き、`:root`（ライト）と 15 個の `[data-theme]` の計 16 系統で定義する。ライト / ダークの 2 系統だけにすると、Nord / Gruvbox / Solarized などでコントラストが崩れる
- ステータス色（緑 / 黄 / 赤）とは別の色相にする。濃淡は `color-mix` で作り、トークンは 4 つに抑える
- 適用先:
  - グリッドの各セル枠。current は 2px、他のスロットは 1px の控えめな枠。実ペインが 2 枚以上のときだけ出し、1 枚のときは出さない
  - タブバーのグリッド内タブ。背景は選択面と衝突するので左端の 3px バーに置く。グリッド外のタブは無色
  - 左一覧の現在行（ツリーとアクティブの両方）。枠と名前を slot 色にする
- スペースの識別には色を使わない。4 色はスロット位置だけを表し、スペースは文字で示す
- 空きスロットはスロット色の薄い破線。フォーカスリングなど、スロット対応以外の選択表示は accent のまま

### 永続化

- キーは `hwc-split-view` の 1 つ。形は `{ openTabs: string[], current: string | null, slots: (string | null)[] }`。開いた順・current・スロットの並び（空きを含む）を保存する
- 復元の正規化（この順）:
  1. 壊れた JSON・型違いは空として扱う
  2. `openTabs` を実在で filter し、重複を除く（最初の出現を残す）
  3. `slots` を実在で filter し、重複を除き（最初の出現を残す）、4 要素に切り詰める。実在しない ID と重複は空きにする（空きの位置は保つ）
  4. `slots` の ID が `openTabs` に無ければ右端に足す
  5. `current` が実在しなければ null
  6. `current` が `openTabs` に無ければ右端に足す
  7. `current` が `slots` に無ければ空き先頭へ。空きが無く 4 未満なら末尾。4 で埋まっていればスロット 1 を置換
  8. `slots` が空で `current` があれば `[current]`
- 未保存なら Herdr のフォーカス中ペインを 1 枚で開く
- 一覧に戻した状態は `current = null` で表す。`hwc-selected-pane` / `hwc-list-open` / `hwc-split` / `hwc-hidden-panes` は使わず、移行もしない
- モバイルも開いたタブと current を復元する。選択の規則は端末で分けず、モバイルでも current スロットを置き換える（表示しないだけ）
- 保存は `openTabs` / `current` / `slots` のどれかが変わったときだけ行う

### プレビュー

- 既存のファイルプレビューは一時タブのまま。履歴にもスロットにも入れない
- 対象ペインが `openTabs` に居る間だけタブに出せる。ペインを選ぶと隠れる（[ADR 0051](0051-agent-html-preview.md)）

## Consequences

- 目に見えるペインの上限は 4 枚。それ以上はタブに積まれ、選ぶと current スロットを置き換える。5 枚以上を同時に見る手段は持たない
- 別スペースのペインを並べられるようになり、セルごとに PR・Git・送信先の文脈が変わる。同じ PR が並ぶこともあれば、別の PR が並ぶこともある
- セルが 1 枚でもグリッドとして扱うが、枠は出さない。枠の役割は複数セルのうちどれが current かを示すことで、1 枚では対象がない。2 枚目を足した瞬間に枠が現れるが、レイアウトが 1x2 に変わる方が大きく、枠の出現は目立たない
- 空きスロットは自動で詰めない。外したタブの位置を保ち、利用者が × で詰める。自動で詰めると、隣のセルの位置が勝手に動く
- 履歴は再読み込みで復元される。消えたペインは落ち、`current` も失われる（再読み込み後は一覧に戻る）
- タブの × はペインを閉じない。最後のシェルもタブから外せるが、Herdr 側のペインとスペースは残る（[ADR 0059](0059-tab-close-detaches.md)）
- 追加帯の 40px は、1 枚表示の本文幅をわずかに狭くする。読み幅（`--hwc-measure`）は中央寄せなので、狭い画面では追加帯を出さない
- タブバーが狭いと、2 段目 + × + 4 色でタブ 1 つが詰まる。横スクロールで逃げる
- スペース名の省略で同名衝突が残る（末尾だけ違う名前など）。`title` と aria にフルを置く
- プロセス取得をスロットと current に絞ると、履歴のシェルのタブ名はペイン名に戻る。止んだコマンド名が残るよりは正しい

## Alternatives

- **タブ内の分割のまま（`splitPanes`）**: 状態を持たず最も簡単。スペースを跨げず、5 枚以上で Eye の運用に戻る
- **ADR 0020 のピン留めボード**: スペースを跨げるが、一覧選択の意味と入れ替えの操作が未決のままだった。開いたペインの履歴を土台にすると、タブ・一覧・セルの対応が 1 つの順序で説明できる
- **自由なドラッグ・リサイズ**: ウィンドウマネージャになる。主端末のスマホでは使えず、PC 専用の複雑さだけが増える
- **5 枚以上をスクロールするグリッド**: セルが小さくなり、会話も端末出力も読めない。4 枚を上限にし、残りはタブで切り替える
- **空きスロットを自動で詰める**: 閉じたペインの位置が変わり、隣のセルが動く。× で明示的に詰める
- **分割トグルを残す**: 1 枚目から 2 枚目を作る経路が 2 つになる。追加帯へのドロップに統一する
- **スペース識別に色を足す**: 4 色がスロット位置を指すので、スペースの色と衝突する。スペースは 2 段目の文字で示す
- **既存キーの移行**: `hwc-split` / `hwc-hidden-panes` の意味は新しいモデルに写せない（非表示はスロット外と同じではない）。初回は Herdr のフォーカスから始める
