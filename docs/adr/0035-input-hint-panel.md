# ADR 0035: 入力欄のモデルと effort は独自の情報パネルで見せ、モデル名を持ち出せるようにする

- Status: Accepted
- Date: 2026-11-07

## Context

入力欄の右下にはペインのモデルと effort を出している（[ADR 0033](0033-launch-model-before-first-message.md)）。狭い画面ではモデル名が省略されるため、全体は `title` の標準ツールチップで補っていた。

標準の `title` はホバーでしか出ず、タッチだけの端末では読めない。キーボードでも開けず、パネル内の文字を選べない。主端末はスマホなので、モデル名を確かめる手段がPCに限られている状態は避けたい。加えて、モデル名を別の場所（設定ファイルや TUI の起動引数）へ書き写す用途があり、画面から持ち出す手段も要る。

同じ入力欄のコンテキスト使用量は、ホバー・タップ・フォーカスのどれでも開く独自のパネルを持っている。配置は `visualViewport` から上か下かを決め、上に収まらなければパネル側をスクロールさせる。

## Decision

### 開閉

- コンテキスト使用量とモデル・effort で 1 つのフック（`src/client/hint.ts` の `useHint`）を共有する。開いた理由（`hover` / `pinned`）・配置・閉じる条件を 1 か所に置き、内容だけを各パネルが持つ
- 札は `button` にする。マウスはホバーで開き、指はタップで開閉する。開いたままにするのはタップで開いたときだけで、外側のタップと `Escape` で閉じる
- フォーカスが `:focus-visible` で入ったときも開く。パネルは開いている間だけ `tabIndex=0` を持ち、Tab でパネル内のコピーボタンへ進める。フォーカスがパネルの外へ抜けたら閉じる
- 省略されたモデル名を範囲選択している間は、札を押しても閉じない

### 配置

- 幅は 240px。画面端から 8px を空ける
- 上に入る高さが足りなければ下へ回し、はみ出す分はパネル側を縦スクロールにする
- 横は右端を札に揃える。右端を揃えると左へはみ出す位置では左端を揃え、どちらも入らないときだけ画面内へ寄せる。判断は純関数 `hintLeft` に切り出してテストする
- 標準の `title` は使わない。タッチとキーボードで読めないため

### 内容

- パネルには省略されていたモデル名（折り返して全部）と effort を出す。モデル名が無いときは effort だけ出す
- モデル名の右にコピーボタンを置く。コピーするのはモデル名だけで、effort は含めない。記号は 24px に保ち、触れる範囲だけ `::after` で 44px に広げる。押すと 1.5 秒だけチェックに変わり、`aria-label` も「コピーしました」に変わる
- クリップボードは既存の `copyText` を使う。http で開いた LAN の端末では `execCommand` に落ちる
- パネルはボタンを含むため `role="group"` とし、コンテキスト使用量の読み上げ専用パネル（`role="tooltip"`）とは分ける
- `title` 専用だった `agentInfoLabel` は消す

## Consequences

- ホバーでは待ち時間なしで開く。`title` の遅延より早く出るが、入力欄の右下に留まる小さなパネルなので操作を妨げない
- パネルは入力欄の上に重なる。文章を読み返しながらモデルを確かめる用途は想定しない
- 分割セルが狭いときは、パネルがセルを越えて隣のセルに掛かる。画面内には収まるが、セル単位では切れない
- コピーの成否は記号と `aria-label` だけで伝える。トーストは出さない
